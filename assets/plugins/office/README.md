# VibeX Office

VibeX Office 将文档、表格和演示文稿工作流完整带入 VibeX。

## 功能

- 在工作区中打开并预览 DOCX、XLSX 和 PPTX 文件。
- 创建和修改 Word 文档与 PowerPoint 演示文稿。
- 分析数据并生成 Excel 工作簿。

## 使用

启用插件后，直接打开受支持的 Office 文件，或在 Agent 任务中描述希望创建、修改或分析的内容。

## 配置

在插件的“配置”页选择预览模式和空闲超时时间。保存后会更新插件根目录的 `config.json`。

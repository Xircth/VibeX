# Open Connector

启用后会出现顶级 Tab「Open Connector」。控制台由本机 Open Connector 运行时提供。首次启用会按官方 Release 下载约 150–175 MiB 的二进制。离线无法完成这次下载。

凭据留在本机数据目录，不写入插件配置。Agent 的五件工具只进入启用之后新建或重新绑定的会话。

## 使用

1. 在设置 → 插件里启用 Open Connector。
2. 打开中央 Tab「Open Connector」。
3. 在控制台里连接应用。授权弹窗应留在本应用内；若被拦截，复制地址并在回来后刷新连接列表。
4. 新开或重新绑定会话后，Agent 才能调用这些工具。

## 配置

延迟加载工具目录默认打开，用于降低内存。允许私有网络和额外信任主机会放宽出站限制，只在你明确需要时打开。

## 数据

连接和密钥在 Host 数据目录的 `plugin-state/vibex.open-connector/`。卸载默认保留。要清空，使用插件配置里的「清除数据」。

## 排障

- 控制台一直停在启动：看插件配置里的最近错误。常见原因是首次下载失败。
- Agent 没有工具：结束当前会话或重新绑定 Agent。
- 授权完成后列表没变：回到控制台刷新。不要指望系统浏览器把结果送回本应用。

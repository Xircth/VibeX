# Agent 纳入关系独立于安装状态与 Registry 可用性

VibeX 用“已添加”表达 Agent 已经进入用户的 Agent 集合，而不用“已安装”代替这一
关系。Built-in Agent 默认已添加；其他 Registry Agent 在用户确认“添加并安装”时
立即成为已添加 Agent、进入统一 Agent 导航带，并在其详情页继续安装、预检查、
认证和修复。

ACP 注册表视图以“已添加”和“可添加”两个 Tab 表达本地纳入关系，两个列表各自
排序；内置 Agent 在已添加列表中置顶，其他 Agent 按名称排序。安装中、待认证、
损坏或需修复不会移除已添加关系，上游 Registry 下架也只会让条目从注册表视图
消失，不会移除本地 Agent 导航带中的 Agent。

Agent 启用状态同样独立于纳入、安装与认证。禁用的 Agent 继续显示，并允许安装、
修复、认证和配置，但不能创建新会话或向既有会话提交新回合；已经在途的回合允许
自然结束。禁用不卸载 Runtime、不注销账户、不删除凭据，重新启用且就绪后既有会话
可以继续使用。

全新安装时，Claude Code、Codex、Gemini、OpenClaw、OpenCode、Cline、Hermes、
CodeBuddy、Kimi Code、Pi、Grok 与 Cursor 默认启用；
用户从 Registry 执行“添加并安装”的普通 Agent 也默认启用。默认启用只表达用户
允许其在就绪后接受执行，不绕过安装、认证、配置或预检查形成的就绪门槛。

Agent 导航带采用一套完全由用户维护的扁平顺序，内置 Agent 可以与普通 Agent
自由交错。全新安装的初始顺序与上述 Built-in Agent 顺序一致；新添加的
普通 Agent 追加到末位固定添加入口之前。迁移保留仍存在 Agent 的原相对顺序，再
补入尚未存在的内置成员。Registry 两个 Tab 的独立排序不改变导航带顺序。

用户取消安装、安装失败或应用退出导致安装中断，都不撤销已经完成的添加操作。
Agent 继续保留在导航带，并保留配置与启用状态；失败显示为需要修复，中断显示为
安装已中断，两者都等待用户明确重试而不在下次启动时自动执行。取消或中断只清理
未提交的托管暂存产物，不触碰外部安装。普通 Agent 仍可由用户移除，Built-in
Agent 仍不可移除。

导航带中的 Agent 图标在空间不足时横向滚动，固定添加入口始终吸附于右侧且不会滚出
视野；两侧渐隐提示仍有内容可滚动。通过键盘或辅助技术聚焦某个不可见 Agent 时，
导航带自动将其滚入可见区域。

Registry 视图展示所有当前官方条目，包括没有当前操作系统或 CPU 架构可用分发包
的条目；后者明确显示平台不支持及缺失目标，不能执行添加并安装。若已添加 Agent
因换机、架构变化或上游停止支持而变得不兼容，它仍保留在导航带并标记为平台不
支持，而不是安装损坏。Built-in Agent 始终默认显示，并在其 Profile 不支持当前
平台时遵守相同的安装与会话限制。

Agent bar 末位添加入口打开设置页内联的完整 Registry 主视图，不使用模态框；Agent
bar 始终保留在顶部，下方 Agent 详情区域切换为 Registry 内容。Registry 保留各自
独立排序的“已添加 / 可添加”Tab、搜索、刷新状态和快照时间；选择其他 Agent、
返回或按 Escape 可回到上次选中的 Agent。当前设置访问期间保留 Tab、搜索词与滚动
位置。

用户执行添加并安装后，新 Agent 立即追加到固定添加入口之前并成为当前选中项，
下方切换到该 Agent 详情页继续展示安装、预检查与配置。Registry 是不透明内容层，
Agent bar 是导航控件层。

Registry 两个 Tab 都使用紧凑的分组列表行而不是卡片网格。每行固定展示图标、名称、
一行简介、版本与可用分发方式；Built-in Agent 只增加低调的内置标签。状态必须用
图标、文字和颜色共同表达。可添加条目的尾部提供添加并安装，不兼容时替换为原因；
已添加条目的尾部显示状态与查看，移除、卸载等破坏性操作只存在于 Agent 详情页。

点击列表行主体以内联 disclosure 展示作者、许可证、仓库链接、Registry id 和完整
分发信息，不离开当前列表。搜索覆盖名称、简介、作者与 Registry id。由于整个视图
已经限定为 ACP 官方 Registry，每行不重复展示官方来源徽章。

Agent bar 的图标以右上角单一健康／就绪状态徽标表达最需要处理的 Agent 状态：
就绪为绿色点，排队或安装中为进度环，待认证或必要配置缺失为琥珀提醒，损坏或
完整性异常为红色修复，不支持当前平台为灰色斜杠，未安装为空心点。启用状态不与
健康状态竞争同一徽标：禁用 Agent 降饱和并叠加暂停标记，仍保留真实健康徽标。
选中 Agent 使用导航带的蓝色选中态；悬停、键盘焦点和 aria-label 必须同时给出
名称、启用状态和完整状态原因。

Built-in Agent 使用随其 Profile 提供的品牌图标，不受 Registry 图标变化影响；普通
Registry Agent 使用经校验并缓存到本地的 Registry SVG，渲染 Agent bar 时不发起
网络请求。未添加条目在 Registry 刷新后可显示最新图标；已添加 Agent 在上游下架
后继续保留最后一次有效图标。图标缺失或无效时使用基于稳定 Agent kind 的通用 ACP
图标，而不使用首字母头像。

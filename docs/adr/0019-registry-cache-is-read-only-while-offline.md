# Registry 离线缓存只用于浏览

VibeX 保存最后一次成功获取并通过 schema 校验的 ACP 官方 Registry 快照。Registry
不可用时，注册表视图继续展示该快照并标明离线状态和最后更新时间，但不能据此
新添加普通 Agent、检查更新或执行更新；这些操作必须先成功刷新官方 Registry。

已添加 Agent、现有安装、配置、会话与启动不依赖 Registry 在线。已经开始并生成
安装锁的任务可以在下载源仍可访问时继续完成；内置 Agent 的权威来源是 Built-in
Agent Profile，因此只要其安装源可访问，Registry 离线不阻止内置 Agent 安装或
修复。

打开 Registry 时，VibeX 先立即渲染本地快照；快照在成功获取后 24 小时内视为新鲜，
过期后按新鲜度策略在后台刷新，手动刷新总是强制获取。新内容必须完整通过 schema
校验后才原子替换快照；校验或获取失败保留最后有效快照。后台刷新不得清空当前内容，
并保留 Tab、搜索词、已展开条目及当前可见 Agent 作为滚动锚点，再将新快照增量合并。
刷新失败时明确显示失败和最后成功时间，普通 Agent 的添加与更新继续禁用；首次没有
快照时显示说明与重试入口。用户发起添加的时刻锁定当前渲染条目的版本，随后完成的
刷新不得改变该次安装目标。

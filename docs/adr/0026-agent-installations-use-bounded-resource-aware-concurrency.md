# Agent 安装使用有限并发与资源锁

VibeX 允许多个 Agent 的安装尝试并行，但默认最多同时运行两个，其余保持可独立
取消的排队状态。用户连续添加 Agent 时，添加关系立即生效，不等待队列执行；单个
Agent 的安装、修复、更新和卸载操作始终串行。

调度器按实际受影响资源加锁：共享 Node、Python、uv、包缓存等发生变更时串行，
互不相关的下载、校验和 Agent 作用域安装可以并行，最终版本切换各自原子提交。
只读探测不占安装并发；认证与配置不占全局安装并发，但必须避开同一 Agent 的卸载
与版本切换。一个操作失败或取消不阻塞其他 Agent。

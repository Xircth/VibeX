# Kanban 会话看板升级设计

## 目标

在 `Kanban` 页签内，把原本仅包含「工作区看板 + 固定右侧栏」的结构升级为「工作区看板 / 会话看板」双视图，并在不改动右侧栏整体结构的前提下，为会话提供：

- 左侧会话列表
- 中部最多 `4` 个只读监控位
- 右侧一个可输入的执行区

本轮补充优化聚焦于 UI 扁平化、中文化、筛选/排序/批量删除，以及监控区操作可见性。

## 范围

### 本次包含

- `Kanban` 双视图切换保持不变，继续通过左侧悬浮箭头切换
- 左侧会话列表改为工具栏 + 折叠标签 + 扁平卡片
- 新建会话改为按钮触发弹窗，不再在列表内直接展示表单
- 新增排序、筛选、批量删除交互
- 新增前端会话删除能力与 Tauri 删除命令
- 监控区卡片压缩布局，并补充「移入执行区」显式按钮
- 将本次触达的会话看板 UI 文案改为中文，`Slot` 标识保持英文

### 本次不包含

- 任务、工作区主看板的结构性改造
- 会话名称持久化字段调整
- 右侧栏外层布局重构

## 核心布局

## 左侧：会话列表

- 顶部保留标题与数量统计
- 标题下方放置 `4` 个工具按钮：
  - `新增`
  - `排序`
  - `筛选`
  - `删除`
- `新增` 打开弹窗，弹窗内仅选择：
  - 归属工作区
  - 编程代理
- 列表默认按「进行中 / 已完成」两段展示
- 两段仅以轻量标签行承载展开/收纳，不再使用独立包裹卡片
- 当用户启用排序或筛选后：
  - 列表切换为单段平铺
  - 不再按「进行中 / 已完成」分组

## 中部：会话监控区

- 最多同时展示 `4` 个会话
- `1~2` 个会话时采用 `2 x 1`
- `3~4` 个会话时采用 `2 x 2`
- 每个监控位保留浅色背景区分：
  - `Slot 1`：蓝
  - `Slot 2`：紫
  - `Slot 3`：绿
  - `Slot 4`：橙
- 卡片头部提供显式 `移入执行区` 按钮，放在 `Slot` 标识左侧
- 消息区只读，不显示输入框

## 右侧：执行区

- 保持现有右侧栏结构不变
- 右侧栏空闲时，左侧点击会话优先进入执行区
- 右侧栏已有会话时，新会话按队列进入监控区
- 点击监控区会话的 `移入执行区` 按钮时：
  - 目标会话进入右侧栏
  - 原右侧栏会话回到监控队尾

## 会话列表卡片规范

- 卡片高度压缩为扁平样式
- 第一行：
  - 左侧显示会话名称
  - 右侧显示最近活跃时间
- 第二行：
  - 左侧显示工作区
  - 其后显示任务标题
- 代理仅展示图标，放在右下角，hover 显示完整名称
- 工作区与时间文字使用统一蓝色
- 列表左侧使用色条标记当前会话所在区域：
  - 监控区沿用对应 `Slot` 色
  - 执行区使用浅红标记

## 工具栏交互

## 新增

- 点击后打开弹窗
- 默认工作区优先使用最近活跃的工作区；不存在时回退到当前项目首个可用工作区
- 默认代理优先使用用户当前默认代理；不存在时回退到首个可用代理
- 会话名称仍由首条消息自动生成

## 排序

- 支持：
  - `名称`
  - `时间`
  - `状态`
- 只要排序生效，就取消「进行中 / 已完成」分段展示
- 提供恢复默认分组入口

## 筛选

- 支持：
  - `工作区`
  - `编程代理`
- 支持多选
- 只要存在筛选条件，就取消「进行中 / 已完成」分段展示
- 提供清空筛选与恢复默认分组入口

## 删除

- 点击后进入批量删除模式
- 每条会话前显示选择框
- 支持多选后统一删除
- 删除前二次确认
- 删除成功后：
  - 刷新对应工作区会话摘要
  - 清理当前会话布局中的已删除会话

## 删除约束

- 正在执行中的会话不允许删除
- 删除时同步清理：
  - `sessions`
  - 同 `session_id` 关联的 `scratch`
  - 排队中的 follow-up 消息
- 级联删除继续依赖现有数据库外键：
  - `execution_processes`
  - `coding_agent_turns`

## 监控区卡片规范

- 顶部：会话名称 + `移入执行区` 按钮 + `Slot` 标识
- 次行：时间、代理、工作区、任务放在同一行，尽量压缩高度
- 主体继续复用只读会话消息视图

## 关键状态

- `isSessionHubVisible`
- `rightSession`
- `monitorSessions[]`
- `lastActiveWorkspaceId`
- `sortField`
- `workspaceFilters[]`
- `executorFilters[]`
- `isDeleteMode`
- `selectedSessionIds`

## 验收标准

- 左侧不再出现内嵌新建会话表单
- 左侧仅保留轻量折叠标签，不再出现厚重分组容器
- 本次会话看板 UI 文案中文化完成，`Slot` 保持英文
- 工具栏四个按钮工作正常
- 会话卡片与监控卡片均明显压缩高度
- 监控区可以通过显式按钮把会话移入执行区
- 执行区 / 监控区 / 左侧色条状态一致
- 排序、筛选、批量删除、创建会话和会话交换逻辑通过前端校验

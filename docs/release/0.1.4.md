# VibeX 0.1.4

## English

VibeX 0.1.4 makes official-account sign-in follow the login and logout process itself, and shows the current account in Agent settings.

### Highlights

- Official subscription status now follows the login or logout result. Codex device authorization and official terminal commands update the signed-in badge when they finish; leftover local session files no longer keep an account marked as signed in after a successful logout.
- Codex ChatGPT sign-in uses the in-app device-code flow. Settings wait for browser authorization, then record the account from that success.
- The official subscription row now shows the current account, such as `Signed in as ada@example.com`, instead of a generic local-session label.
- Auth modes are tabs. Account modes persist immediately; API Key and custom credential modes stay draft until save. Codex tabs are ChatGPT, API Key, then Provider.
- After login, logout, or saving credentials, settings run an authentication-only preflight. Switching tabs no longer starts a full agent preflight.
- Cursor official-account detection uses the platform token store, and the Cursor icon size matches the other agents.
- The configuration filename and open-folder control sit beside the auth tabs, with the full path available on hover.

## 中文

VibeX 0.1.4 让官方账号登录状态跟随登录和退出过程本身，并在 Agent 设置中显示当前登录账户。

### 主要更新

- 官方订阅登录状态改为跟随登录或退出结果。Codex 设备码授权和官方终端命令完成后会更新登录徽章；成功退出后，本地残留会话文件不再把账号继续显示为已登录。
- Codex 的 ChatGPT 登录改为应用内设备码流程。设置页等待浏览器确认后，以该次授权成功作为登录结果。
- 官方订阅登录下方改为显示当前账户，例如「当前登录账户：ada@example.com」，不再使用「本机已有官方会话」。
- 鉴权模式改为标签页。账号模式会立即保存；API Key 和自定义凭据模式仍保持草稿，直到保存。Codex 标签顺序为 ChatGPT、API Key、Provider。
- 登录、退出或保存凭据后，只运行鉴权预检查。切换标签不再触发完整 Agent 预检查。
- Cursor 官方账号检测改为使用平台令牌存储，Cursor 图标尺寸与其他 Agent 一致。
- 配置文件名和打开文件夹入口移到鉴权标签旁，悬停可查看完整路径。

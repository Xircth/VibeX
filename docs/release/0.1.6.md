# VibeX 0.1.6

## 中文

VibeX 0.1.6 把插件市场做成可安装的产品目录，补齐 Agent 鉴权与 Composer 引用，并让委派子会话在时间线里能跟完。

### 主要更新

- 设置 → 插件增加市场 Tab。官方按发布者 `vibex` 归类，主题分类用「效率」「Agent」「工作流」等；同一条可以同时出现在官方和主题分类里。列表在页内滚动，发布者、分类、版本跟在插件名右侧。
- `npx vibex plugin add` 支持市场页、Git（`#tag` / `#commit` 锁定）、GitHub Release `.vxp`、本地档案和链接开发目录。`list` / `update` / `remove` 操作同一 Host catalog；卸载默认保留配置，链接开发目录不会被删除。
- 已退役的「VibeX Collaboration」不再与「多智能体协同」并排出现，目录只保留后继包。
- Agent 设置补齐鉴权模式、模型供应商和原生配置。设置侧栏「技能」改为 Skill，「指令」改为快捷指令。
- Composer 的 `@` 引用收成一块面板，可插入文件、会话、提交和快捷指令。
- 委派子会话在时间线中展示生命周期与结果，父会话能打开、跟随和结束子任务。
- macOS 发行包按 Developer ID 签名并公证 Chromium / CEF 运行时；本地开发签名从 `.env.local` 读取。

## English

VibeX 0.1.6 turns the plugin marketplace into an installable catalog, finishes Agent auth and Composer references, and lets delegated child conversations complete in the timeline.

### Highlights

- Settings → Plugins adds a marketplace tab. Official is the `vibex` publisher; topic categories such as Productivity, Agent, and Workflow are separate. One listing can appear under Official and its topic. The list scrolls in place, and publisher, category, and version sit beside the name.
- `npx vibex plugin add` accepts a marketplace page, Git (`#tag` / `#commit` lock), a GitHub Release `.vxp`, a local archive, or a linked development directory. `list` / `update` / `remove` talk to the same Host catalog. Uninstall keeps config by default and never deletes a linked source directory.
- The retired VibeX Collaboration listing no longer sits beside Multi-agent; the catalog keeps the successor package only.
- Agent settings cover auth modes, model providers, and native configuration. The sidebar labels are Skill and Quick instructions.
- Composer `@` references share one panel for files, conversations, commits, and quick instructions.
- Delegated child conversations show lifecycle and results on the timeline; the parent can open, follow, and finish the child work.
- macOS release builds Developer ID-sign and notarize the Chromium / CEF runtime. Local development signing reads `.env.local`.

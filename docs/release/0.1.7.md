# VibeX 0.1.7

## 中文

VibeX 0.1.7 把打开项目后的默认工作区、终端、活动列表和会话面接到正确事实上。

### 主要更新

- 打开项目默认进入项目文件夹当前分支，不再因为已有 Git Worktree 就切到隔离工作区。
- 左侧活动栏可拖拽排序。右侧「执行进程」改为工作区活动：Agent 会话（含时间跨度图）、后台长期任务、错误与警告。
- Agent 通过 ACP 拉起的长期命令出现在终端列表，例如 `Codex-01`。命令结束或 Agent 释放后移除，只读，不能写入。
- 会话列表支持搜索、排序、归档和新建。
- 欢迎页会打开项目根目录下的一个文件。
- 折叠 Turn 时同一条 assistant 文本只出现一次；文件变更卡片不再撑出会话列。
- Web Preview 地址栏回车只导航当前预览标签，弹窗仍打开外层标签。
- 失焦桌面通知窗口保持透明，不再盖住 toast 卡片。
- 工具栏、侧栏跟随应用语言；Notes 输入框不再裁切第一个字。
- Grok 在 `bypassPermissions` / `dontAsk` 下自动跳过权限确认。
- 本机 Antigravity 可发现 `agy_acp_server.par`。
- 多智能体协同补齐剩余 Agent 身份；父 Agent 拿到 `task_id` 后必须立刻等待结果。

## English

VibeX 0.1.7 connects the default workspace, terminals, activity list, and conversation surfaces to the facts they should have been showing.

### Highlights

- Opening a project lands on the project folder at the current branch. Existing Git worktrees no longer steal the default workspace.
- The left activity rail can be reordered. The right-hand Processes entry becomes workspace activity: Agent sessions with a span chart, background long-running tasks, and errors or warnings.
- Agent long-running ACP commands appear in the terminal list as names like `Codex-01`. They are read-only and leave the list when the command exits or the Agent releases them.
- The session list supports search, sort, archive, and create.
- The welcome view opens a file at the project root.
- Collapsing a Turn no longer duplicates the same assistant text. The files-changed card stays inside the conversation column.
- Enter in the Web Preview address bar navigates the current preview tab. Popups still open an outer tab.
- The unfocused desktop toast window stays transparent instead of covering the toast card.
- Toolbar and sidebar follow the app language. The Notes input no longer clips the first character.
- Grok skips permission prompts in `bypassPermissions` / `dontAsk`.
- Local Antigravity discovery includes `agy_acp_server.par`.
- Multi-agent collaboration maps the remaining Agent identities. After a parent Agent receives a `task_id`, it must wait for the result.

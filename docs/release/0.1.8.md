# VibeX 0.1.8

## 中文

VibeX 0.1.8 降低桌面 Host 空闲开销，把 Agent 安装写进用户环境，并补齐会话提问、纠偏与查询。

### 主要更新

- Windows 桌面不再用 WebGL 玻璃效果。Chromium 等到第一次打开预览才启动，通知窗口等到第一次 toast 才创建。隐藏的终端和预览面板会卸载。
- Git 状态解析按进程缓存，面板 Git 与目录列举离开异步运行时；大体积未跟踪文件不再做整文件行数统计。
- 打开会话只加载最近时间线窗口，流式写入合并落盘，ACP 终端历史与 SQLite / 日志 / diff 上限下调。
- Agent 安装写入用户环境（PATH、npm 全局前缀、uv tools、用户 bin），不再维护私有 shim 树。会话启动优先 PATH 上的同名命令，再回退 Installation lock。
- Runtime 与 ACP 默认安装 npm `latest`，也可分别指定版本。二者不匹配只提示风险，不阻止安装。用户在终端自行升级后，下次检查会重绑路径与版本。
- 会话增强：提问卡片支持跳过；Composer「纠偏」显示等待读取 / 已读取；用 `@` 点名另一段会话时，Agent 只读查看标题、工作区、分支和最近消息。
- 外观增加强调色，立即作用于主按钮、选中态与焦点，并记住选择。
- 插件市场对已安装条目显示「已安装」。
- 桌面发布流水线先构建一次前端，并缓存 CEF 运行时。

## English

VibeX 0.1.8 cuts idle desktop Host cost, writes Agent installs into the user environment, and finishes session questions, steering, and lookup.

### Highlights

- Windows chrome no longer uses a WebGL glass surface. Chromium starts on the first preview, and the toast window is created on the first notification. Hidden terminal and preview panels unmount.
- Git resolution is cached per process. Panel Git and directory listing leave the async runtime. Large untracked files skip whole-file line counts.
- Opening a conversation loads the latest timeline window. Streaming persists on a coalesced cadence. ACP terminal history and SQLite / log / diff ceilings are lower.
- Agent installs write into the user environment (PATH, the npm global prefix, uv tools, and the user bin) instead of a private shim tree. Session launch prefers the same-named command on PATH, then the Installation lock.
- Runtime and ACP default to npm `latest` and can be pinned separately. A mismatch is a warning, not a blocker. After a terminal upgrade, the next check rebinds path and version.
- Session enhancement: question cards can be skipped; Composer steering shows waiting / read; `@` conversation links make the Agent read title, workspace, branch, and recent messages only.
- Appearance adds an accent color for primary buttons, selection, and focus. It applies immediately and is remembered.
- The plugin marketplace marks listings that are already installed.
- Desktop release builds the frontend once and caches the CEF runtime.

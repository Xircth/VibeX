# VibeX 0.1.9

## 中文

VibeX 0.1.9 引入无限画布式会话看板，并集中修复 Windows 上的 ACP 启动、导入会话与界面问题。

### 一、修复

1. 导入会话后继续对话不再把原始 ACP 会话重新加载进内存，也不会卡在不可继续的状态；跟进会冷启动新的 Agent session。
2. 多处展开选项列表（含会话配置与 Composer `@` 引用）不再因列表位置漂移或选中态回跳而点错。
3. Windows 上 Agent 会话配置（模式 / 模型 / 推理等）选择后会等到实时快照对齐再清除待定值，避免显示回弹到旧值。
4. 导入大量本地会话改为增量扫描与后台导入，避免一次载入全部转录导致内存溢出。
5. Windows 上 Claude Code、Codex、Pi 的 ACP 环境只验证并启动 ACP 适配器，不再把 PATH 上的 vendor CLI 当成启动门，也不再经 `CLAUDE_CODE_EXECUTABLE` / `CODEX_PATH` 注入。
6. Windows 模型供应商预设投影到 Claude Code、Codex、Pi 原生配置时不再丢失密钥、绑定状态或字段。
7. Windows 打开尚未 Git 初始化的项目时，会等仓库初始化完成后再创建会话。
8. Windows 使用 Codex 时，`$` 触发的 Skill 会按 `$name` 发送，不再被斜杠菜单改成 `/$skill`。
9. Windows 偶发的全局界面比例异常改为缩放桌面 WebView，而不再使用 CSS zoom。
10. Windows 导入会话时补齐缺省时间字段，并保留正确的 Agent 图标。
11. 文件预览与会话时间线中的 Markdown 能把 Mermaid 图渲染为内联 SVG，节点文字不再被截断。
12. Windows 使用 Codex 时，适配器占用冲突与 `.cmd` shim 会优先改走同目录 `.exe`，并在共享占用时重试清理。
13. Windows 日志与会话状态同步异常：会话进度变化会通知工作区列表，启动失败会带上安装诊断摘要，而不只留下锁状态。
14. 桌面窗口图标按 PNG 字节解码；等待终端、权限或提问时不再把安静的数据流误判为模型挂起。

### 二、优化

1. Windows ACP 连接稳定性：PATH 上的适配器优先、启动环境消毒、占用冲突重试，以及更明确的会话启动失败原因。
2. Pi Agent 设置支持原生插件的查看、添加与移除。
3. 多处前端显示与渲染：时间线只在真正滚到顶部时加载更早记录、工具预览体积设上限、隐藏 toast 窗口与看板拖放预览更轻。

### 三、更新

无限画布式会话看板：支持在无限画布上创建 Agent 会话、展开对话、分组、导入与拖放，并提供历史停靠栏（后退 / 前进）。外观设置可在列看板与无限画布之间切换。设置页支持搜索并跳转到匹配项。创建 Pull Request 时可用指定 Agent 生成标题和描述。

## English

VibeX 0.1.9 introduces the infinite session canvas and concentrates on Windows ACP launch, history import, and UI fixes.

### Fixes

1. Continuing an imported conversation no longer reloads the original ACP session into memory or leaves the thread unresumable. Follow-ups cold-start a new Agent session.
2. Expanded option lists (session config and Composer `@` references) no longer drift or snap the selection back.
3. On Windows, Agent session config (mode / model / reasoning) waits for the live snapshot before clearing the pending value, so the UI does not bounce to the previous choice.
4. Large local-history imports scan and import incrementally in the background instead of loading every transcript at once.
5. On Windows, Claude Code, Codex, and Pi sessions validate and launch the ACP adapter only. A vendor CLI on PATH is not a launch gate, and `CLAUDE_CODE_EXECUTABLE` / `CODEX_PATH` are not injected.
6. Windows Model Provider preset projection onto Claude Code, Codex, and Pi native config no longer drops keys, bound state, or fields.
7. Opening a project that is not yet a Git repository on Windows waits for git init before creating a session.
8. Codex skills triggered with `$` are sent as `$name` instead of being rewritten to `/$skill` by slash menus.
9. Occasional Windows-wide UI scale errors zoom the desktop WebView instead of using CSS zoom.
10. Windows history import fills missing timestamps and keeps the correct Agent icon.
11. Markdown in file preview and the conversation timeline renders Mermaid as inline SVG so node labels are not clipped.
12. Codex occupancy conflicts on Windows prefer a sibling `.exe` over npm `.cmd` shims and retry cleanup on sharing violations.
13. Windows logging and session-state sync: conversation progress notifies the workspace list, and launch failures include the install diagnostic excerpt instead of leftover lock state.
14. Desktop window icons decode from PNG bytes. Quiet streams are no longer treated as a hung model while a terminal, permission, or question is still open.

### Improvements

1. More stable Windows ACP connections: PATH adapter first, sanitized launch env, occupancy retries, and clearer session-launch errors.
2. Pi Agent settings can list, add, and remove native plugins.
3. Frontend display and render work: older timeline pages load only at the real top, tool previews are capped, and the toast window plus board drag previews stay lighter.

### Features

Infinite session canvas: create Agent sessions, expand conversations, group cards, import, and drag on an unbounded board, with a history dock for back/forward. Appearance can switch between the column board and the canvas. Settings search jumps to the matching row. Pull Request titles and descriptions can be generated by a chosen Agent.

# VibeX 0.2.0

## 中文

VibeX 0.2.0 接入 Qoder Agent，补齐无头 Server 与桌面同一套 Host 能力，并集中修复会话中断、重发、上下文丢失，以及 Windows 上的设置、看板与内置浏览器问题。macOS 桌面与 Server 发行物改为仅提供 Apple Silicon。

### 一、修复

1. Markdown 预览标签页可以内联渲染 HTML 和图片，不再只剩源码或空白。
2. Windows 上选择器组件的展开、选中和关闭不再点错或卡住。
3. Windows 设置页底部保存栏贴回内容区，不再整体偏移。
4. Windows 上偶发的模型供应商列表空白会重新读出已保存预设。
5. Codex「关闭 WebSocket」写入原生配置后立即生效，不再只改界面开关。
6. 看板卡片、分组和列表的运行 / 待审状态不再错位或空白。
7. 看板会话列表的「新建会话」会真正打开创建流程。
8. 无头 Server 补齐原先只在桌面存在的会话、设置和表面能力（尚未做独立生产环境实测）。
9. Windows 上 Grok 鉴权配置按当前模式显示，不再露出空白或错位控件。
10. Agent 会话配置（模式 / 模型 / 推理）不再在打开或跟进时被写回默认值。
11. 重发消息会带上正确的检查点上下文，而不是空会话或错乱历史。
12. 中英文界面日期、ACP 预设名称和部分文案按当前语言显示。
13. 新对话发第二条消息时，不再把上一回合的 Assistant 输出刷回来，再在本回合结束后消失。
14. 点击中断后会真正取消在途回合；旧输出不会继续写，也不会和新回合并行。
15. 重发失败后再发新消息时，旧输入不会残留并被再次发出，也不会出现两条并行对话。
16. 强制退出进程后继续同一对话，会按可恢复绑定重载前文，而不是冷启动丢上下文。
17. 中断 / 重发不再写入非法会话绑定状态，避免 SQLite CHECK 约束让重发直接失败。
18. 会话事件表不再堆积悬空 `turn_id`；写入时也不再反复撞外键约束。
19. 重启后第一次打开终端即可用，不再报 `Terminal ... not found`、必须关掉标签再建。
20. 远程桌面访问令牌不再被 `JSON.stringify` 明文带出。
21. 中文界面日期不再显示英文；ACP 预设显示名称而不是原文 key；屏幕阅读器 `aria-label` 走翻译。
22. `feedback_check` 只有摘要时工具卡片仍显示；旧版 skill 标签不再露出本机绝对路径。
23. 设置页、选择器和插件目录的圆角、原生下拉和底部留白对齐设计规范。
24. 内置浏览器 URL 栏可以连续输入、提交和纠错，不再吞字或跳走。
25. 工作区切换左侧栏菜单时，welcome 标签页会保留，而不是被卸掉。

### 二、优化

1. Windows 下减少不必要的重绘和隐藏面板工作，界面更跟手。
2. 计量统计看板按会话事件和厂商日志折叠用量，空值和未知不再填成零。
3. 无限画布的拖放、分组和列表刷新更稳，卡顿更少。
4. Windows 上 Codex 与 ZCode 的非标准供应商可以投影到原生配置并出现在列表里。
5. Windows 正文字体与字距更接近系统设计。
6. 工作区 Dock 的隐藏 / 显示与分栏切换走同一套逻辑，welcome 和预览标签不再互相挤掉。

### 三、新增

1. 支持 Qoder Agent：按内置档案安装、官方订阅鉴权和启动令牌接入，可创建会话并走统一 ACP 管线。
2. macOS 只发布 Apple Silicon 桌面安装包和 Server 归档。Intel Mac 不再进入发布矩阵。

## English

VibeX 0.2.0 adds Qoder as a first-class Agent, brings the headless Server onto the same Host surfaces as the desktop, and concentrates on turn cancel, resend, context restore, and Windows settings, kanban, and in-app browser bugs. macOS desktop and Server artifacts are Apple Silicon only.

### Fixes

1. Markdown preview tabs render inline HTML and images instead of leaving a blank or source-only pane.
2. Windows selectors open, select, and dismiss without missing the intended row.
3. The Windows settings save bar sits on the content pane instead of drifting.
4. The Windows Model Provider list reloads saved presets instead of going blank.
5. Codex "disable WebSocket" writes through to native config and takes effect.
6. Kanban cards, groups, and lists keep running / needs-review state instead of going empty or skewed.
7. New session in the kanban session list actually opens create.
8. Headless Server now exposes the conversation, settings, and surface commands that previously lived only on desktop (not yet proven in a separate production soak).
9. Windows Grok auth controls follow the current mode instead of showing a blank or shifted field.
10. Agent session config (mode / model / reasoning) is not rewritten to defaults on open or follow-up.
11. Resend carries the checkpoint context instead of an empty or scrambled history.
12. Chinese and English dates, ACP preset names, and remaining copy follow the active language.
13. The second message in a new conversation no longer flashes the previous Assistant turn, then drops it when the new turn finishes.
14. Cancel actually stops the in-flight turn. Old output does not keep writing or run in parallel with the next turn.
15. After a failed resend, a new message does not replay the leftover input or start a second parallel turn.
16. After a force-quit, continuing the same conversation reloads recoverable context instead of cold-starting.
17. Cancel / resend no longer write an illegal session binding that trips the SQLite CHECK and fails the resend.
18. The conversation event table no longer accumulates dangling `turn_id` values or retries foreign-key failures on write.
19. The first terminal after restart works. It no longer reports `Terminal ... not found` until the tab is closed and reopened.
20. The remote-desktop access token is no longer emitted in plaintext by `JSON.stringify`.
21. Chinese dates stay in Chinese. ACP presets show names, not raw keys. Screen-reader `aria-label`s are translated.
22. A `feedback_check` with only a summary still renders a tool card. Legacy skill labels no longer leak an absolute machine path.
23. Settings, selectors, and the plugin catalog use the design-system radius, custom selects, and bottom spacing.
24. The in-app browser URL bar accepts continuous typing, submit, and correction without dropping characters.
25. Switching the workspace activity rail keeps the welcome tab instead of unmounting it.

### Improvements

1. Windows drops extra paints and hidden-panel work so chrome stays responsive.
2. The usage dashboard folds conversation events and vendor logs. Missing values stay missing instead of becoming zero.
3. Infinite-canvas drag, grouping, and list refresh hitch less.
4. Windows Codex and ZCode nonstandard providers project into native config and appear in the list.
5. Windows body type is closer to the system font metrics.
6. Workspace dock hide / show and column switching share one path, so welcome and preview tabs do not knock each other off.

### Features

1. Qoder is a built-in Agent: install from the profile, official-subscription auth, launch token, and the same ACP session pipeline.
2. macOS ships Apple Silicon desktop and Server artifacts only. Intel Mac is no longer in the release matrix.

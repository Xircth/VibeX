# VibeX 0.2.2

## 中文

VibeX 0.2.2 把桌面交互收成产品菜单，把科研技能做成可开关的官方插件，并把 Xiaomi MiMo Code 接进同一套 Agent 管线。会话里可以选中一段内容复制、引用或 Fork；Agent 的警告不再混进助手回复。

### 一、修复

1. 远端 ACP 安装会真正完成，不再排进队列后空转。
2. 桌面在 Host 事件总线起来之前写日志，不再 panic。
3. Agent 发出的警告、配置提示和上下文压缩通知记成会话通知，不再当成助手消息。
4. 会话无法继续时给出重绑定提示，而不是静默失败。
5. 远程安装 Agent 走用户环境，不再停在本机排队。
6. Linux clippy 不再误伤平台窗口常量。

### 二、优化

1. 工作区各表面右键都走产品菜单：有动作就弹出，没动作就吞掉，不再露出浏览器的返回 / 刷新 / 检查元素。
2. 会话时间线可以拖选一段内容，出现复制、引用、Fork 工具条。
3. 文件树可以展开/折叠全部，并复制树结构。
4. HTML 文件在预览里按沙箱打开，脚本可运行，但进不了 VibeX 主文档。
5. Agent 创建的文件会自动打开预览。
6. 设置里可以缩放界面；桌面走 webview 原生缩放，弹层不会跑偏。
7. 模型供应商页可以一次管理多个连接，并检查 Agent 的 ACP 更新。
8. Windows 窗口控件改成圆形；终端输出在进程重启后重新挂上。
9. 桌面标题栏与窗口控件叠在内容上，不再额外占一行。
10. Host `/health` 区分已发布构建和调试构建。
11. DeepSeek 会话历史、浏览器外壳和会话命名一起收齐。
12. 会话分叉切点和在途纠偏与既有会话语义对齐。

### 三、新增

1. 官方「科学研究」插件：146 项科研技能，按 10 个领域开关。默认只注入通用科研方法 13 项，其余在插件配置里按需打开。源码在 `assets/plugins/science`。
2. Xiaomi MiMo Code 作为内置 Agent：官方订阅、官方 API 和供应商鉴权走同一套安装、探测和会话管线。
3. 从会话消息流选中内容后可以插入 Composer 引用片段，Token 显示所选前四个字。
4. 项目可以把多段会话导出成一个会话包。
5. Composer 支持图片等媒体附件。
6. 插件 Skill 可以按领域开关；关掉的领域不会注入任何 Agent。

## English

VibeX 0.2.2 turns desktop right-clicks into product menus, ships scientific research Skills as a gated official plugin, and adds Xiaomi MiMo Code to the same Agent pipeline. You can select conversation text to copy, quote, or fork. Agent warnings no longer land in the assistant transcript.

### Fixes

1. A remote ACP install finishes instead of sitting in a no-op queue.
2. Desktop logging before the Host Event Bus is up no longer panics.
3. Agent warnings, config notices, and context-compaction notices are session notices, not assistant messages.
4. When a session cannot continue, the UI asks you to rebind instead of failing silently.
5. Remote Agent installs go into the user environment instead of stalling on the local queue.
6. Linux clippy no longer trips over platform window constants.

### Improvements

1. Workspace surfaces use product context menus. Empty or forbidden hits swallow the event, so Back / Reload / Inspect Element never appear.
2. The conversation timeline lets you drag-select a span, then copy, quote, or fork from the toolbar.
3. The file tree can expand or collapse all, and copy its structure.
4. HTML files preview in a sandboxed frame: scripts run, the VibeX document stays unreachable.
5. Files the Agent creates open a preview automatically.
6. Settings can zoom the UI. Desktop uses native webview zoom so overlays stay aligned.
7. Model Provider settings manage multiple connections and check ACP updates.
8. Windows window controls are circular. Terminal output reattaches after a process restart.
9. Desktop chrome overlays the content instead of taking an extra title row.
10. Host `/health` distinguishes a published build from a debug build.
11. DeepSeek history, browser chrome, and session naming land together.
12. Conversation fork cuts and in-flight steering follow the existing session semantics.

### Features

1. Official Scientific Research plugin: 146 Skills in 10 domains. Only the 13 general methods inject by default; turn other domains on in plugin settings. Source lives in `assets/plugins/science`.
2. Xiaomi MiMo Code as a built-in Agent: official subscription, official API, and provider auth use the same install, probe, and session pipeline.
3. Selected conversation text can be inserted as a Composer quote token, labeled with the first four characters.
4. A project can export several conversations as one pack.
5. Composer accepts image and other media attachments.
6. Plugin Skills can declare a domain switch. Closed domains are not injected into any Agent.

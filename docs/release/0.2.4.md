# VibeX 0.2.4

## 中文

VibeX 0.2.4 给 Composer 加上项目引用，排队中的会话输入在 Host 重启后会继续执行，提示词增强可以中途取消。会话提问收成卡片，用户消息里的图片单独展示，看板在切换工作区标签时不再卸载。

### 一、修复

1. Host 重启后会释放未完成认领的排队输入并继续投递，不再把尚未到期的认领当成仍在处理。
2. 取消卡住的回合会清掉「正在连接」提示，不再一直显示在等。
3. 取消回合的握手诊断不再当成会话通知。
4. Grok 权限模式 `always-approve` 会跳过确认；`bypassPermissions` 不再重复传参。
5. 会话配置不再把厂商「推理强度」和标准 Reasoning Effort 并排重复。
6. Codex WebSocket 开关写入后能读回来，不再保存后弹回。
7. ACP 会话准备超时（默认 60 秒），`session/new` 卡住不再无限等待。
8. 远程 SSH 探测按多行脚本执行，能读到远端 Host 健康和安装路径。

### 二、优化

1. 用户消息中的图片从正文拆出，以附件展示。
2. Agent 提问在时间线收成可展开的提问卡片。
3. 看板在切换工作区标签时保持挂载，监控会话不会丢。
4. 状态栏项目指示可以点击切换项目。
5. 启用科研等领域技能包前会确认技能数量。
6. 提示词增强可以取消；开始新的增强会中止上一次。
7. Host 隧道默认端口改为 17891，安装命令带上公网地址。
8. 一次性 Agent 任务（提示词增强等）使用独立工作区，并带上该 Agent 的会话默认配置。
9. Grok 权限选项收成：询问 / 自动执行 / 跳过权限确认。

### 三、新增

1. Composer `@` 面板新增「项目」Tab：点名仍存在于 VibeX 的 Project。Token 显示项目名，Hover 为绝对路径，发给 Agent 的消息展开为该路径。
2. 提示词增强可取消。
3. Host 隧道安装可指定公网 IP / 域名，脚本也会探测公网地址。

## English

VibeX 0.2.4 adds project references to Composer, resumes queued conversation inputs after a Host restart, and lets you cancel prompt enhancement. Agent questions become cards. Images in user messages render as attachments. The kanban board stays mounted when you switch workspace tabs.

### Fixes

1. A Host restart releases unfinished input claims and continues dispatch. A claim whose deadline has not elapsed is no longer treated as still in flight.
2. Cancelling a hung turn clears the connecting warning instead of leaving it on screen.
3. Cancel-handshake diagnostics are not session notices.
4. Grok `always-approve` skips permission prompts. `bypassPermissions` is not passed twice.
5. Session config no longer shows a vendor thought-level control beside the standard Reasoning Effort option.
6. The Codex WebSocket switch persists after save instead of snapping back.
7. ACP session preparation times out after 60 seconds by default, so a stuck `session/new` does not wait forever.
8. Remote SSH probes run as a multi-line script and can read Host health and the install path.

### Improvements

1. Images in user messages are split out of the body and shown as attachments.
2. Agent questions render as expandable cards on the timeline.
3. The kanban board stays mounted when switching workspace tabs, so monitor sessions are not torn down.
4. Status-bar project chips switch the open project.
5. Enabling a scientific-research domain pack asks you to confirm the Skill count.
6. Prompt enhancement can be cancelled. Starting a new enhancement aborts the previous one.
7. Host tunnel defaults to port 17891. The install command includes the public address.
8. One-shot Agent tasks such as prompt enhancement use an isolated workspace and the Agent's session defaults.
9. Grok permission options are: ask, auto, always-approve.

### Features

1. The Composer `@` panel adds a Projects tab for Projects that still exist in VibeX. The token shows the project name, hover shows the absolute path, and the Agent receives that path.
2. Prompt enhancement can be cancelled.
3. Host tunnel install can take a public IP or domain. The script also probes for a public address.

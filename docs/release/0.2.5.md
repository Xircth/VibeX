# VibeX 0.2.5

## 中文

VibeX 0.2.5 给供应商新建表单加上可搜索的预置模板，图片预览支持缩放、平移和标注并拖回 Composer，用量按会话事件出账。无头 Host 可以用 `vibex-server pairing` 签发配对码，有效期最长 30 天。

### 一、修复

1. 创建工作区检出仓库超时时会失败并提示重试，不再一直卡住；git 调用不再继承会拖死检出的环境与 hooks。
2. 内置浏览器把配置目录放在用户数据目录或其直接子目录，不再因嵌套路径无法创建 profile。
3. 用量把每回合 token 累加，而不是后一次覆盖前一次；历史会话会补回模型名，看板不再把它们归到「未提供」。
4. 文件树按工作区记住展开状态；懒加载列表回来后不会把仍有效的展开目录清掉。
5. 看板画布和用量视图不再抢走工作区会话的消息流；分组节点不再把尺寸抖动写进布局。
6. 设置里打开发行说明走系统浏览器。

### 二、优化

1. 图片预览支持滚轮缩放、拖移、适应窗口和 1:1，以及矩形、椭圆、画笔、文字标注；标注后的图可以拖进 Composer。
2. 会话附件可预览；看板不支持的格式会直接说明。
3. Agent 提问卡片版式更干净，带「提问」标记。
4. 设备配对默认 30 分钟，可选 6 小时、1 天、7 天或 30 天。
5. Codex 推理强度增加 Max 和 Ultra。
6. 流式代码高亮复用已完成的行，减少闪烁。

### 三、新增

1. 官方插件 ProviderSwitch：启用后，设置 → Agent → 鉴权 → 供应商的新建表单列出按 Agent 整理的预置端点。点选只填名称、地址和模型，密钥仍由你填写。禁用后模板从新建表单消失，已经保存的供应商不受影响。
2. `vibex-server pairing [--preset companion|workstation] [--ttl 30m|1h|6h|1d|7d|30d]` 在终端签发配对邀请。
3. 新贡献点 `provider.model.catalog`：插件向新建表单提供无密钥填表模板。模板在保存之前不是供应商预设，也不是导入候选项。

## English

VibeX 0.2.5 adds searchable provider presets to the new-provider form, lets you zoom, pan, and annotate images before dropping them into Composer, and accounts usage from conversation events. Headless Host can issue pairing codes with `vibex-server pairing`, valid for up to 30 days.

### Fixes

1. Creating a workspace fails with a retry prompt if repository checkout times out, instead of hanging. Git invocations no longer inherit environment and hooks that can stall checkout.
2. The embedded browser keeps profiles in the user-data directory or an immediate child of it, so nested paths no longer fail profile creation.
3. Usage accumulates per-turn tokens instead of letting a later sample overwrite an earlier one. Historical sessions get their model names backfilled so the board does not group them as unprovided.
4. The file tree remembers expanded folders per workspace. A lazy listing no longer clears expansions that are still valid.
5. Canvas and usage views no longer steal the workspace conversation stream. Group nodes no longer write size jitter into the layout.
6. Opening release notes from Settings uses the system browser.

### Improvements

1. Image preview supports wheel zoom, pan, fit, 1:1, and rectangle, ellipse, brush, and text marks. Annotated images can be dropped into Composer.
2. Conversation attachments can be previewed. Unsupported formats on the board say so.
3. Agent question cards are cleaner and tagged as questions.
4. Device pairing defaults to 30 minutes, with optional 6 hour, 1 day, 7 day, or 30 day codes.
5. Codex reasoning effort adds Max and Ultra.
6. Streaming code highlighting reuses completed lines to reduce flicker.

### Features

1. Official plugin ProviderSwitch: after you enable it, Settings → Agent → Authentication → Providers lists per-agent preset endpoints on the new-provider form. Choosing one fills name, URL, and model; you still type the key. Disable it and the presets leave the form. Saved providers stay.
2. `vibex-server pairing [--preset companion|workstation] [--ttl 30m|1h|6h|1d|7d|30d]` issues a pairing invitation from the terminal.
3. New contribution point `provider.model.catalog`: plugins contribute keyless fill-in templates to the new-provider form. A template is not a saved provider preset and is not an import candidate until you save.

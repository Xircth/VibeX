# VibeX 0.2.6

## 中文

VibeX 0.2.6 把深色模式做成独立夜景，修了 Windows 首次启动、睡眠和 GPU 崩溃后的窗口绘制，并把 Pi 的自定义供应商并进统一的模型供应商管理。会话列表可以搜索和批量删除，Pi 扩展斜杠命令会出现在 Composer。

### 一、修复

1. Windows 首次启动时，无框窗口先就绪，CEF 和 Plugin Worker Node 不再挡在设置路径上，Defender 扫描不会把引导冻住。
2. Windows 睡眠或 GPU 崩溃后，CEF/WebView2 继续绘制；主窗口等到首次绘制后再显示。
3. 只复用 Ready 的 ACP 会话。取消未得到确认时，下一回合不会喂给脏连接。
4. 继续对话会恢复这条会话自己的 ACP id，而不是同工作区里的兄弟会话。宿主历史只在真正冷启动时注入；Codex 记录里泄漏的 Previous conversation 会被去掉。
5. 并发 ACP 回合不再互相卡在「生成中」；`session/cancel` 没有响应时会重拉连接。
6. 切换会话时立刻丢掉上一会话的时间线，不再闪一下旧内容。
7. 宿主图片按路径复用 blob URL，卸载时释放，长会话不再泄漏渲染内存。
8. 电脑睡眠醒来后，工作区清理、diff 轮询和 PR 监视不再瞬间连打十几次。
9. 设置里切到官方订阅前会确认；未签名的订阅模式也可以先登录再保存。
10. 公网隧道设置命令确认后仍保留，健康探测会重试，中继失败有可操作说明。
11. Grok 的低推理强度会出现在会话控件和提示词增强里；增强只覆盖 Agent 真正声明的项。
12. 自动会话标题会去掉宿主历史前缀。

### 二、优化

1. 深色模式使用 Hangar / Mirage 材质和 Pearl Ink 强调色，夜间选择态、主操作和层级仍然清楚。
2. Windows 和 Linux 把应用 logo 放到标题栏前缘，和无框窗口控件在一起；macOS 仍在后缘。
3. 压缩上下文按钮默认隐藏，需要在通用设置里打开。
4. 工作区列表和会话中枢侧栏共用同一套搜索和批量删除。
5. 看板画布用右键拖移平移。
6. 设置、引导和对话框改用 Astryx TextInput。
7. 历史导入的时间范围和扫描范围更简单；桌面和 Server 共用同一套目标匹配。

### 三、新增

1. ProviderSwitch 从上游同步预置目录，新建供应商表单里的模板保持更新。
2. Pi 自定义供应商并入统一的模型供应商管理；Pi 面板只保留运行时和信任控件。
3. Composer 能发现并补全 Pi 扩展斜杠命令，不必等 pi-acp 的命令目录到达。

## English

VibeX 0.2.6 makes dark mode a first-class night scene, keeps the Windows window painting after first launch, sleep, and GPU crashes, and folds Pi custom providers into the shared model-provider manager. Session lists can search and bulk-delete. Pi extension slash commands appear in Composer.

### Fixes

1. On Windows first launch, frameless chrome is ready before AppState setup. CEF and Plugin Worker Node no longer sit on the setup path, so Defender scanning cannot freeze onboarding.
2. After sleep or a GPU crash, CEF/WebView2 keep painting. The main window stays hidden until first paint.
3. Only Ready ACP sessions are reused. A cancel that the agent never acknowledged will not serve the next turn.
4. Follow-up restores this conversation's stored ACP id instead of a sibling session in the same working directory. Host history is injected only on a true cold start. Leaked Previous conversation blocks are stripped from Codex transcripts.
5. Concurrent ACP turns no longer stall each other at generating. An unacknowledged `session/cancel` relaunches the connection.
6. Switching conversations drops the previous timeline immediately, so old rows do not flash into the next session.
7. Host images reuse one blob URL per path and revoke it on unmount, so long sessions do not leak renderer memory.
8. After the host wakes from sleep, workspace cleanup, diff polls, and PR monitors skip burst catch-up.
9. Switching to official subscription asks for confirmation. You can log in from an unsigned subscription mode without first persisting the mode.
10. The host tunnel setup command stays after confirm. Health probes retry. Relay failures map to actionable copy.
11. Grok low effort appears in session controls and prompt enhancement. Enhancement only applies overrides the agent actually advertises.
12. Auto-named conversation titles drop host-history prefixes.

### Improvements

1. Dark mode uses Hangar / Mirage materials and Pearl Ink accents so selection, primary actions, and hierarchy stay visible at night.
2. Windows and Linux put the app logo on the leading edge of the title bar with the frameless controls. macOS keeps it on the trailing edge.
3. Compact-context is hidden unless you enable it in General settings.
4. Workspace lists and the session hub sidebar share the same search and bulk-delete controls.
5. The session canvas pans with right-drag.
6. Settings, onboarding, and dialogs use Astryx TextInput.
7. History import time-range and scan-scope controls are simpler. Desktop and Server share destination matching.

### Features

1. ProviderSwitch refreshes bundled provider templates from upstream sources.
2. Pi custom providers join the shared model-provider manager. The Pi panel keeps runtime and trust controls.
3. Composer discovers Pi extension slash commands that pi-acp omits from the ACP catalog, and can complete plugin commands before the agent catalog arrives.

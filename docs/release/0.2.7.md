# VibeX 0.2.7

## 中文

VibeX 0.2.7 把 Windows 内置浏览器放到独立的拥有弹出层上，避免和 WebView2 叠在一起后页面冻住或 GPU 崩溃。ACP 子进程中途退出会结束当前回合并可以重连。标题栏 Logo 菜单可以开新窗口、回首页和切换最近项目。

### 一、修复

1. Windows 上 CEF 页面不再作为 WebView2 的子窗口。页面在 Tauri 窗口拥有的弹出层上绘制，GPU 崩溃（`0x80000003`）和睡眠后不再把界面冻住。
2. Chromium 消息泵不再从 `CefDoMessageLoopWork` 里重入。delay=0 的工作先离开 UI 线程再投递，嵌套泵不会丢掉绘制。
3. 额外的本地应用窗口共用主窗口的 WebView2 配置目录。从 IPC 再开一套独立环境会让新窗口空白、关不掉，调用方也会卡住。
4. ACP 子进程或 stdio 在回合中途断开时，当前回合记为 `connection_closed`，并清掉卡住的 active turn。没有输出的静默回合会重拉连接。
5. Prompt 不再调用 `session/new`。会话线程由 Prepare / Resume 绑定；这里再新建会把 Codex 分到另一条线程。
6. Composer 替换正文走系统撤销栈，不再把 React 赋值绕过撤销。
7. 看板画布自己接管右键拖移。不再依赖 React Flow 的 `panOnDrag`，Chromium 才能持续收到 mousemove。
8. 文件树截断列表回来后，仍然有效的展开目录不会被清掉。

### 二、优化

1. 标题栏 Logo 收成独立菜单：新建应用窗口、回到首页、最近项目。
2. `title` 不再弹出系统原生提示。悬停由应用内提示层显示，位置避开视口边缘。
3. Pi 推理字段从 Pi 面板抽到统一的模型供应商表单。新声明的推理档位默认不含 `xhigh`。
4. Agent 鉴权 Tab 按 Agent 记住。从已绑定的模型供应商切到官方订阅会立即保存，不会被下一轮加载弹回。
5. 桌面打开设置可以带到指定路径。
6. 会话中枢侧栏搜索同时匹配会话名和对话内容；空看板仍显示四个状态分组。
7. 应用图标重新生成。

### 三、新增

1. Windows CEF 拥有弹出层宿主（`VibeXBrowserHost`），与 WebView2 分层绘制。
2. 原生 `title` 的应用内悬停提示。

## English

VibeX 0.2.7 hosts the Windows embedded browser in an owned popup so it no longer freezes or crashes the GPU under WebView2. An ACP child that dies mid-turn fails that turn and can reconnect. The title-bar logo menu opens a new window, goes home, and switches recent projects.

### Fixes

1. On Windows, CEF pages are no longer a child of WebView2. They paint in a popup owned by the Tauri window, so GPU crashes (`0x80000003`) and sleep no longer freeze the UI.
2. The Chromium message pump no longer re-enters from `CefDoMessageLoopWork`. delay=0 work hops off the UI thread before it is posted, so a nested pump cannot drop paints.
3. Extra local app windows share the main WebView2 profile. Creating a second environment from IPC leaves the new window blank and unclosable, and freezes the caller.
4. If the ACP child or stdio dies mid-turn, that turn is `connection_closed` and the stuck active turn is cleared. A silent turn with no output reconnects.
5. Prompt no longer calls `session/new`. The host binds the thread with Prepare or Resume. Creating one here forks Codex onto another thread.
6. Composer replacements go through the native undo stack instead of assigning React state around it.
7. The session canvas owns right-drag pan. It no longer relies on React Flow `panOnDrag`, so Chromium keeps sending mousemove.
8. A truncated file-tree listing no longer clears expanded folders that are still valid.

### Improvements

1. The title-bar logo is its own menu: new app window, back home, recent projects.
2. Native `title` tips are suppressed. Hover uses an in-app tooltip that stays inside the viewport.
3. Pi reasoning fields move from the Pi panel onto the shared model-provider form. Newly declared reasoning omits `xhigh` by default.
4. The Agent auth tab is remembered per agent. Switching to official subscription from a bound model provider persists immediately and does not snap back on reload.
5. Opening Settings on desktop can land on a specific path.
6. Session hub search matches conversation content as well as names. An empty board still shows the four status groups.
7. App icons are regenerated.

### Features

1. Windows CEF owned-popup host (`VibeXBrowserHost`), composited above WebView2.
2. In-app hover tooltips for native `title` attributes.

# VibeX 0.2.8

## 中文

VibeX 0.2.8 把内置浏览器换成 wry 宿主页面。对话框、菜单等浮层出现时，会先冻住当前画面再藏起原生窗口，避免被 HWND 挡住。官方插件可以从 marketplace 安装并启用，Open Connector 成为内置插件。项目树把普通文件夹当成一等项目，刚 `git init` 的空仓库也能开会话。状态栏会显示插件 MCP 是否在线。

### 一、修复

1. 刚 `git init`、尚未有提交的仓库可以创建会话。读取符号 HEAD 上的默认分支并补一个空提交，不再因 UnbornBranch 失败，也不会误切到过期的 `main`。
2. 从列表隐藏项目会真正从实时项目流里移除，导入列表也不再显示已隐藏项。
3. 原生浏览器 HWND 永远画在 HTML 之上。浮层打开时先冻帧、再隐藏原生页面；捕获失败也会藏窗口，避免对话框被挡住。
4. 冻帧会等宿主确认并在屏外解码后再藏 HWND，关闭浮层时先显示页面再清占位，不再闪空白或挡住表单。
5. 创建会话的名称栏使用原生 Astryx TextInput。Composer 粘贴走系统撤销栈，Ctrl+Z 会先撤销这次粘贴。
6. 工作区选中新会话时立刻高亮执行区里的那条，不再停在上一会话。
7. 从左侧列表拖到无限画布时，预览和落点卡片保持列表里测到的宽度。切换项目会关掉仍开着的创建会话表单。
8. 原生检查器只在 debug 构建里出现。
9. 插件投影失败后丢掉过期 MCP，状态不再显示已死的工具。
10. 会话选择器列表有最大高度。Welcome 标签画布为 `#fafafa`。
11. 委派子会话在 Prompt 前完成 ACP 绑定。子会话通过 sessions 绑定，不会落到未绑定连接上。
12. 切换会话时提示词增强仍跟着当前会话。长流式输出保持在可视区域。
13. 看板 PageDown 不再误打开用量面板。
14. 会话图片缩略图从磁盘加载，生产环境不再空白。
15. Windows 能解析并拉起本机 CLI。空的 host-family sidecar 会被跳过，broker 会重新绑定。
16. Agent 子进程会带上 WinINET / Clash TUN 混合端口代理环境。
17. Open Connector 安装、MCP token、app.tab 宿主表面和配置表单走同一条可用路径，不再弹出多余控制台。
18. Grok MCP 服务器 id 经过清理，状态栏能列出 workerHttp 上的实时工具。

### 二、优化

1. 工作区顶栏、标签、文件树和会话纸面共用同一套灰底与玻璃材质，macOS / Linux / 深色模式一致。
2. 选中标签两侧曲线更大，悬停药丸保持白色且不被裁切。标签间距收紧，选中标签与面板连在一起。
3. 左侧栏点击互斥。侧分屏可以拖出幽灵位，也可以取消分屏。
4. 设置里的紧凑文本框有内边距，输入控件回到原生 Astryx。供应商目录从可搜索弹出层打开。
5. Composer 待办显示在输入框上方，有边框、无多余滚动条。会话计划卡片在 Composer 里复用。
6. 预览图使用磨砂并收起多余铬件。MCP 描述默认折叠，点开再看。插件状态用指示灯表示。
7. 项目表单、项目栏和浏览器铬件对齐。首页栏和 `git init` 更快。

### 三、新增

1. wry 宿主浏览器替代 CEF 预览，作为应用内浏览器。
2. 浏览器选取模式保持武装，直到工具栏按钮关掉。可连续点选多个元素；截图在斗篷后排队，避免高亮把下一次点击交给页面。
3. 浏览器插件接通 MCP，并整理浏览器铬件。
4. 官方插件从 marketplace 安装、展示卡片与标识，安装后可直接启用。插件仓库拆到独立 GitHub 仓库。
5. Open Connector 作为官方内置插件发布。
6. 项目树把普通文件夹当作一等节点。非 Git 目录可以创建会话，嵌套 Git 仓库是独立项目。
7. 把左侧栏按钮拖到面板上即可左右分屏。
8. 状态栏显示插件 MCP 是否在线。

## English

VibeX 0.2.8 puts the in-app browser on a wry host page. When a dialog or menu opens, the native surface is freeze-framed and then hidden so an HWND cannot cover the HTML. Official plugins install and enable from the marketplace, and Open Connector ships as a builtin. The project tree treats ordinary folders as first-class projects, so a freshly `git init`'d repo can open a session. The status bar shows whether plugin MCP is live.

### Fixes

1. A repo that has been `git init`'d but has no commits can create a session. The host reads the symbolic HEAD branch, births an empty commit on that default, and ignores a stale requested name such as `main`.
2. Hiding a project removes it from the live projects stream. Hidden rows also drop out of the imported list.
3. Native browser HWNDs always paint above HTML. Opening a floating layer freeze-frames then hides the native page. A failed capture still hides the HWND so a dialog is never covered.
4. The freeze waits for every native host to ack and decodes offscreen before the HWND hides. Closing a layer shows the page before clearing the placeholder, so the form is not covered and the page does not flash blank.
5. The create-session name field uses native Astryx TextInput. Composer paste goes through the system undo stack, so Ctrl+Z undoes that paste first.
6. Selecting a new workspace session highlights the execution session immediately instead of keeping the previous in-list row.
7. Dragging a session from the left list onto the infinite canvas keeps the measured list-card width on the overlay and the dropped node. Switching projects unmounts a create-session form that was still open.
8. The native inspector is gated to debug builds.
9. A failed plugin projection drops stale MCP, so status no longer lists dead tools.
10. The session selector list has a max height. The Welcome tab canvas is `#fafafa`.
11. Delegated child conversations finish ACP bind before Prompt. Children bind through sessions, not an unbound connection.
12. Prompt enhancement follows the conversation after a switch. Long streams stay in view.
13. PageDown on the kanban board no longer opens the usage panel.
14. Conversation image thumbnails load from disk, so production thumbs are not blank.
15. Windows resolves and spawns local CLIs. Empty host-family sidecars are skipped and the broker rebinds.
16. Agent children inherit WinINET / Clash TUN mixed-port proxy env.
17. Open Connector install, MCP token, app.tab host surface, and config share one usable path. No extra console window.
18. Grok MCP server ids are sanitized. The status bar lists live tools on workerHttp.

### Improvements

1. Workspace top bar, tabs, file tree, and session paper share one gray and glass chrome across macOS, Linux, and dark mode.
2. Selected tab side curves are larger. Hover pills stay white and unclipped. Tab spacing is tighter, and the selected tab joins the panel.
3. Left-rail clicks are exclusive. Side splits restore ghost targets and can unsplit.
4. Compact settings fields have inner inset. Inputs return to native Astryx. The provider catalog opens from a searchable popover.
5. Composer todos sit above the input with a border and no extra scrollbar. The conversation plan card is reused in Composer.
6. Preview chrome is frosted and stowed. MCP descriptions stay hidden until requested. Plugin status uses indicator lights.
7. Project form, rail, and browser chrome line up. The home rail and `git init` are faster.

### Features

1. The wry host browser replaces the CEF preview as the in-app browser.
2. Browser pick stays armed until the toolbar button is toggled off, so several elements can be sent together. Cropped screenshots queue behind a cloak so the highlight does not hand the next click back to the page.
3. The browser plugin connects MCP and the browser chrome is polished.
4. Official plugins install from the marketplace with cards and glyphs, and can be enabled on install. Plugin repos split out to GitHub.
5. Open Connector ships as an official builtin plugin.
6. The project tree treats ordinary folders as first-class nodes. Non-Git folders can create sessions. Nested Git repos are independent projects.
7. Dropping a left-rail button onto the panel splits the left dock.
8. The status bar shows plugin MCP liveness.

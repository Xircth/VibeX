# VibeX 0.3.0

## 中文

VibeX 0.3.0 把文件搜索放进文件树，重做首次引导和右侧栏，并加入官方插件「电脑控制」。会话会记住已确认的模式和模型。内置浏览器在切换视图时先收起原生页面，设置里可以直接选用内置的无痕配置。

### 一、修复

1. 清除本地数据后，损坏的会话全文索引会被拆掉并重建。设置里的失败提示显示后端返回的原文。
2. Antigravity 冷恢复不再退回 Default 和默认模型。已确认的 YOLO 或模型选择会写进绑定，下次恢复先重放这条选择。
3. 第一次 Prompt 之前，如果 Agent 把已确认的会话配置改回去，主机会再写一次。Agent 最终落在另一个值上时，会出现一次拒绝提示。Grok 的模型目录更新并入列表，不改当前会话正在用的模型。
4. ACP 目录过期后，「保存为默认值」仍能保存当前会话里已经确认的控制项。思维等级别名会映射到目录实际公布的键。
5. 新建的 VPS 隧道保留公网地址。配对邀请和可达性检查不再丢掉这个来源，连接码不区分大小写。手填地址保留端口，缺省为 17891。
6. 从列表点开会话，或父会话跳到新会话时，工作区会马上切过去，不再停在空白的新会话草稿上。
7. 看板和工作区切换视图时，原生浏览器先收起再换页面。回来时等宿主宽度稳定后再显示，避免页面盖住下一屏，或按旧宽度闪一下。
8. 画布拖动卡片时跟着手指走，只在松开时吸附到网点。邻卡参考线仍在拖动中显示。
9. Markdown 里的 `\[ \]`、`\( \)`、数学围栏和 align 环境在解析前被保护，反斜杠不再被吃掉。
10. Composer 附件不再溢出。插件 Worker 帧有明确上限。远程插件表面在加载前就计入状态。
11. 桌面客户端（例如 ChatGPT 应用）只影响已安装排序和徽章，不替代 CLI，也不跳过 ACP。

### 二、优化

1. 右侧栏每个用户消息一张甘特图，时间和文案与转录一致。Agent 会话列表有上限，并收在后台任务之上。
2. 变更树从左缘调整宽度。文件数显示在「变更」旁边，行数在悬停时出现。删除内容按 merge-base 读取，内联和分栏都能看见。
3. 笔记可以像转录选区一样引用进 Composer。空笔记占位跟随项目语言。运行中的应用页不再放元素拾取器。
4. Git 面板和提交框重写。会话行的批量更新带上上一序号。Git 读写离开界面线程，避免拖住会话和操作。
5. 按钮和文本框对齐 Astryx。Windows 上文本框用实色填充，不再被画成系统原生输入框。新建会话不再手填名称，由宿主自动命名。
6. 首次引导留在安装页，直到跳过或离开。Git 安装步骤去掉。文件查看器默认是资源管理器或 Finder。选中的 Agent 在进入工作台前完成安装、登录和预检。安装页标题带步进省略号；系统要求减少动效时，省略号保持不动。引导里的 Agent 栏按内容收拢，最多 440 像素。安装结果用通过或失败的卡片显示。文案改为「正在使用的 Agent」和「默认正在使用的 Agent」。
7. 设备登录成功后记下已登录账号，并显示在引导和 Agent 栏。看得见的会话在空闲清理时保持绑定。
8. 文件树搜索框和选项按钮收进一行，字号 12px。浏览器地址栏同样是 12px。
9. 去掉不再使用的差异面板、进程面板和依赖。会话卡片、右键菜单、编辑器分栏、终端架、工具卡和桌面通知一并收紧。

### 三、新增

1. 官方插件「电脑控制」。Agent 可以读取并操作你授权共享的桌面窗口：无障碍树、截图、键鼠、按窗口或应用或全屏授权，以及全局紧急停止。共享窗口边缘的呼吸光由设置里的指示条开关控制。启用后，新开或重新绑定的会话才会带上它的 MCP 和 Skill。
2. 文件搜索从文件树标题展开。大小写、整词和正则放在输入框外的一个菜单里。Ctrl+Shift+F 打开文件树和这个输入框。清空查询后回到文件树，点空白处关闭输入框。
3. 创建会话后，画布立刻放一张收起的会话卡，并按当前缩放移过去。审阅中的会话可以在画布会话列表里标成完成，不必先打开对话窗口。
4. 内置浏览器设置把「无痕」当作内置配置，可在「新标签页使用」里直接选择，不能再建成同名配置。设置页显示宿主代理是否已继承，并改用 12px 的按钮和选择器。
5. 增加 GitHub CLI 的安装路径。插件状态栏可以挂在 MCP 就绪之后的远程表面。插件二进制帧可以在宿主和 Worker 之间传递。

## English

VibeX 0.3.0 puts file search on the file tree, reshapes first-run setup and the right sidebar, and adds the official Computer Use plugin. A session keeps the mode and model you confirmed. The in-app browser parks its native page before a view switch, and browser settings can select the built-in private profile directly.

### Fixes

1. After local data is cleared, a broken conversation full-text index is removed and rebuilt. The settings failure shows the backend error text.
2. An Antigravity cold resume no longer falls back to Default and the default model. A confirmed YOLO or model choice is stored on the binding and replayed on the next resume.
3. Before the first Prompt, the host writes a confirmed session config again if the agent pins it back. A one-time rejection notice appears when the agent settles on a different value. A Grok model-catalog update joins the list and leaves this session's current model where it is.
4. After the ACP catalog expires, Save as Default still stores the controls confirmed in the current session. Thought-level aliases map onto the key the catalog actually advertises.
5. A newly created VPS tunnel keeps its public origin. Pairing invitations and reachability checks no longer drop that origin, and connection codes match regardless of case. A typed address keeps its port, or uses 17891 when none is given.
6. Opening a session from the list, or jumping from a parent session to a new one, switches the workspace immediately instead of staying on a blank new-session draft.
7. Switching the kanban or workspace view parks the native browser before the next page. Coming back waits until the host width is stable, so the page does not cover the next surface or flash at the old width.
8. Dragging a canvas card follows the pointer and snaps to the lattice only on release. Neighbor guides still draw during the drag.
9. Markdown `\[ \]`, `\( \)`, math fences, and align environments are protected before parsing, so backslashes are not consumed.
10. Composer attachments no longer overflow. Plugin worker frames have an explicit limit. A remote plugin surface counts toward status before it finishes loading.
11. A desktop client such as the ChatGPT app only affects the installed sort and badge. It does not replace the CLI path or skip ACP.

### Improvements

1. The right sidebar shows one gantt chart per user message, with the same times and labels as the transcript. The agent-session list is capped and sits above background tasks.
2. The changes tree resizes from its left edge. The file count sits beside Changes, and line counts appear on hover. Deletions are read from the merge-base, so they stay visible in both inline and split views.
3. A note can be quoted into Composer the same way as a transcript selection. The empty-note placeholder follows the project language. The element picker is gone from the running app page.
4. The git panel and commit box are rewritten. Conversation row batches carry the previous sequence. Git reads and writes leave the UI thread so they do not stall sessions or commands.
5. Buttons and text fields follow Astryx. On Windows, text fields use an opaque fill instead of the system native input. New sessions no longer ask for a name; the host names them.
6. First-run setup stays on the install page until you skip or leave it. The Git install step is gone. The file viewer defaults to File Explorer or Finder. Selected agents install, sign in, and preflight before the workbench opens. The install title trails dots that step while installation is on screen; reduced motion leaves the dots steady. The setup agent bar hugs its content, up to 440 pixels. Install results use a pass or fail card. The copy says Active Agents and Default active Agent.
7. A successful device login records the signed-in account and shows it in setup and on the agent bar. A visible session stays bound through idle cleanup.
8. The file-tree search field and its options button sit on one row at 12px. The browser address bar is 12px as well.
9. Unused diff and process panels, and unused dependencies, are removed. Session cards, context menus, editor splits, the terminal shelf, tool cards, and the desktop toast are tightened with them.

### Features

1. Computer Use ships as an official plugin. An agent can read and act in desktop windows you choose to share: accessibility trees, screenshots, keyboard and pointer input, grants per window, application, or the full screen, and a global emergency stop. The breathing aura on a shared window follows the indicator switch in settings. After you enable the plugin, only a session opened or rebound later receives its MCP and Skill.
2. File search expands from the file-tree title. Case, whole word, and regular expression live in one menu outside the field. Ctrl+Shift+F opens the file tree and that field. Clearing the query restores the tree, and a click on empty space closes the field.
3. Creating a session places a collapsed card on the canvas immediately and pans to it at the current zoom. An in-review session can be marked done from the canvas session list without opening a conversation window.
4. In-app browser settings treat Private as a built-in profile. It can be selected for new tabs and cannot be created again under that name. The settings page shows whether the host proxy was inherited, and its buttons and selects are 12px.
5. A GitHub CLI install path is included. The plugin status bar can host a remote surface after MCP is ready. Plugin binary frames can pass between the host and a worker.

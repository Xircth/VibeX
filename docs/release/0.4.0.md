# VibeX 0.4.0

## 中文

VibeX 0.4.0 围绕协作空间（群聊与私聊）体验升级、数字员工记忆与交互卡片、内置 ZCode Agent、Tauri UI 调试器插件以及前后端运行时性能和稳定性展开更新。

### 一、修复

1. **Agent 运行时与 ACP 连接稳定性**
   - 修复 Windows 下系统临时目录权限受限或触发 `ACCESS_DENIED` 时 ACP 启动失败的问题，统一使用可写的短路径临时目录处理 ACP 会话与探测任务。
   - 修复 `cancel_prompt` 在收到非当前活动 Prompt 的取消指令时直接丢弃回执通道、导致活动 ACP 连接被误判断开的 Bug。
   - 修复 Grok ACP 会话锁竞争时丢失 `sid` 的问题，并恢复协作空间内助手会话控制项与会话摘要展示。

2. **协作空间、群聊与私聊**
   - 修复协作空间内连接级状态变更（未携带 `session_id`）时未清理成员 `connecting` 启动标记、导致成员头像加载态残留的问题。
   - 修复成员身份回填迁移事务与外键级联删除逻辑，并在成员配置列变更时自动触发数据库迁移重建。
   - 修复私聊审批卡片授权范围文案（`此私聊始终允许`）与线程级权限落盘逻辑，以及侧边栏卡片消息预览显示原始标记文本的问题。
   - 修复群聊头像在小尺寸列表中的描边与重叠比例、从群聊打开成员标签页的标题格式（`<群聊> · <成员>`），以及将成员加入群聊时误移动其私聊会话的问题。

3. **对话流、预览与插件**
   - 修复会话行投影同步、JSONL 历史记录写入、终端清理、排队输入以及时间线合并中的边界问题。
   - 修复内联 HTML 预览（`HtmlPreviewBlock`）在首次落盘后固定跳过后续写盘的问题，改为按目标路径与代码内容组合去重，确保流式修改同一文件时磁盘内容实时更新。
   - 修复插件页签与内置页签共享 ID 时的工具栏重复渲染问题，并移除状态栏内联渲染的 Computer Use 窗口选择器。

### 二、优化

1. **协作空间与侧边栏交互重构**
   - 重构协作侧边栏为扁平化会话列表，支持自定义联系人分组、Spotlight 成员/群聊搜索弹窗、内联新建群聊，以及带未读徽标与标签环的叠层群聊头像（`GroupAvatar`）。
   - 统一群聊与私聊消息输入框（`SessionComposerInput`），支持 `@成员` 提及胶囊（`MemberMention`）、气泡内回执状态标识与跨私聊动态提示行。
   - 优化协作投递信封与未读上下文打包策略：仅展开最近 20 条未读消息并折叠更早历史，超额自动唤醒显式标记为 `limit_reached` 并在轮次结束后释放，空闲成员会话自动进入休眠。

2. **前后端性能优化**
   - 将 `ConversationTimelineRegistry` 的监听器按 `conversationId` 分桶（`listenersByConversation`），流式输出时仅通知当前会话的订阅组件，避免全局广播引发的跨会话重渲染。
   - 为协作消息组件 `SpaceMessageBody` 增加 `React.memo` 与卡片/交接解析结果缓存，并在 `MessageStream` 中将成员与花名册查找预索引为 $O(1)$ 哈希表。
   - 在 `CollaborationSpaceCollectionPanel` 中当窗口处于后台隐藏状态（`document.visibilityState === 'hidden'`）时跳过定时轮询，并将汇总与记忆请求改为并发加载。
   - 优化后端 `crates/conversations` 侧边栏 SQLite 投影查询，对用户侧消息跳过冗余子查询，并改用 `sort_by_cached_key` 降低列表排序开销。

3. **架构治理与工作台体验打磨**
   - 拆分会话投影、宿主服务与设置页大型模块为职责清晰的子模块，并引入架构不变量检查（`arch:check`）与插件零特权门禁（`plugin:no-privilege`）。
   - 调整工作台会话状态配色映射，将 HTML 预览精简为无边框画布并支持右键快捷菜单（重新加载 / 检查元素），同步更新中英双语 README 与插件原生架构图。

### 三、新增

1. **数字员工身份、交互卡片与记忆层**
   - 新增持久化协作成员身份体系与 `(member, thread)` 级会话路由，支持成员一对一私聊（`direct:<id>`）以及成员仓库写入隔离策略（默认 `WriteIsolated` 独立 worktree，可选 `WriteSerialized`）。
   - 新增 `ask_person`（向成员或用户提问）与 `request_approval`（请求审批）结构化交互卡片及配套 MCP 工具、宿主接口，并支持带深度与单轮上限控制的结构化多 Agent 交接（Handoff）。
   - 新增协作成员记忆层（Member Memory），支持活动摘要、作用域事实沉淀、BM25 检索召回、记忆蒸馏钩子以及 `memory_search` / `memory_write` MCP 工具。

2. **内置 ZCode Agent 与 Tauri UI 调试器插件**
   - 新增内置 **ZCode** Agent，支持自动发现系统 PATH 与版本管理器（`nvm`、`fnm`、`volta`）中的 Node 运行时并校验 `node:sqlite` 支持能力。
   - 新增 **Tauri UI 调试器**（`tauri-ui-debugger`）插件，提供主窗口悬浮球、页面元素拾取器、开发态 JSX 源码位置标注（`data-vx-source` / `data-vx-component`）及输入框草稿令牌插入能力。

3. **会话工作台增强与插件平台能力**
   - 会话视图新增会话目标栏（Session Goal Bar）、异步任务栏（Async Task Bar）与跟进提问建议（Prompt Suggestion）。
   - 完成 L0 插件能力代理（Capability Broker）、动态命令路由与无头模式（Headless Bootstrap）启动支持。

## English

VibeX 0.4.0 upgrades the collaboration workspace across group and direct chats, introduces member identities with interactive cards and a persistent memory layer, adds built-in ZCode agent support and the Tauri UI Debugger plugin, and delivers runtime stability and performance improvements across the stack.

### Fixes

1. **Agent Runtime & ACP Connections**
   - Fixed ACP launch failures on Windows when default temp directories hit `ACCESS_DENIED` or permission restrictions by routing ACP sessions and conversation probes through writable short scratch directories.
   - Fixed `cancel_prompt` dropping its response channel when receiving a non-matching prompt cancellation, preventing active ACP connections from being erroneously disconnected.
   - Preserved the session ID (`sid`) during Grok ACP session lock races, and restored assistant session controls and session summary display in collaboration spaces.

2. **Collaboration Space, Group Chat & Direct Chat**
   - Fixed connection-level status transitions (without a `session_id`) leaving stale `connecting` bootstrap indicators on collaboration space members.
   - Wrapped collaboration identity backfill in a single transaction with foreign-key cascades, and ensured database migrations rebuild when member configuration columns change.
   - Fixed thread-scoped approval grant copy (`Always allow in this DM`) and persistence in direct chats, and fixed sidebar previews rendering raw card markup instead of the card label.
   - Fixed `GroupAvatar` separator rings and member scaling at list sizes, formatted member tabs opened from a group as `<group> · <member>`, and prevented adding a member to a group from moving its direct chat session.

3. **Conversations, Preview & Plugins**
   - Resolved edge cases in conversation row projector sync, JSONL transcript recording, terminal cleanup, queued input handling, and timeline merging.
   - Fixed inline HTML preview (`HtmlPreviewBlock`) skipping subsequent disk writes after the initial save by tracking `(targetPath, code)` pairs so streaming updates to the same file persist reliably.
   - Hid duplicate plugin tab views that share a built-in toolbar tab ID, and stopped rendering the Computer Use window picker inline in the status bar.

### Improvements

1. **Collaboration Sidebar & Chat Experience**
   - Redesigned the collaboration sidebar with a flat chat list, user-defined contact groups, a spotlight member/group search modal, an inline group creator, and stacked cyclic `GroupAvatar` icons with unread badges and tag rings.
   - Unified `SessionComposerInput` across group and direct chats with `MemberMention` chips, in-bubble delivery receipt checks, and cross-DM notice lines.
   - Refined collaboration delivery envelopes and missed-context packing: only the 20 most recent missed messages are expanded while older ones collapse into a single summary line, over-cap auto-wakes are held visibly as `limit_reached` until the turn ends, and idle member sessions sleep automatically.

2. **Frontend & Backend Performance**
   - Partitioned `ConversationTimelineRegistry` listeners by `conversationId` (`listenersByConversation`) so streaming updates only notify subscribers of the active conversation instead of triggering global re-renders.
   - Wrapped `SpaceMessageBody` in `React.memo` with memoized card/handoff parsing and mention contexts, and pre-indexed member and roster lookups into $O(1)$ maps in `MessageStream`.
   - Paused periodic polling in `CollaborationSpaceCollectionPanel` while the window is hidden (`document.visibilityState === 'hidden'`) and parallelized collection and memory fetches.
   - Short-circuited SQLite turn-resolution subqueries for user-origin messages in `crates/conversations` sidebar queries and switched sidebar sorting to `sort_by_cached_key`.

3. **Architecture & Workbench Polish**
   - Split monolithic conversation projection, host service, and settings modules into focused submodules, backed by automated architecture invariant checks (`arch:check`) and plugin privilege gates (`plugin:no-privilege`).
   - Remapped session workbench status colors, streamlined `HtmlPreviewBlock` into a frameless canvas with a right-click context menu (`Reload` / `Inspect`), and refreshed the bilingual READMEs and architecture diagrams.

### Features

1. **Collaboration Member Identity, Cards & Memory Layer**
   - Added persistent collaboration member identities with `(member, thread)` session routing, 1-on-1 direct member chats (`direct:<id>`), and configurable repository write policies (`WriteIsolated` worktree isolation by default, `WriteSerialized` opt-in).
   - Added structured `ask_person` and `request_approval` interactive cards with MCP tools and host operations (`card.list` / `card.resolve`), plus structured multi-agent handoffs with depth and per-turn limits.
   - Added the member memory layer with activity summaries, scoped facts, BM25 recall, distillation hooks, and `memory_search` / `memory_write` MCP tools.

2. **Built-in ZCode Agent & Tauri UI Debugger Plugin**
   - Added built-in **ZCode** agent support with automatic Node runtime discovery across `PATH` and version managers (`nvm`, `fnm`, `volta`) and `node:sqlite` capability verification.
   - Added the **Tauri UI Debugger** (`tauri-ui-debugger`) plugin with a main-window floating ball, interactive element picker, dev-mode JSX source annotations (`data-vx-source` / `data-vx-component`), and composer draft token insertion.

3. **Conversation Workbench & Plugin Platform**
   - Added the Session Goal Bar, Async Task Bar, and Prompt Suggestions to the conversation workbench.
   - Completed the L0 plugin capability broker, dynamic command router, and headless bootstrap support.

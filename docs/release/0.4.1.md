# VibeX 0.4.1

## 中文

VibeX 0.4.1 围绕远程连接与内网穿透体验升级、协作空间点名投递与草稿持久化、工作区 MP4 视频预览与页签刷新，以及前后端运行时稳定性展开更新。

### 一、修复

1. **协作空间投递、点名与会话流**
   - 修复顺序轮次（Round）槽位在输入派发前被提前解绑的问题，保留开放轮次及轮次中间步骤中的 Bot `@点名` 投递关系，并在 `redeliver_deferred` 中自动重试排队输入。
   - 修复直接私聊（BotSpace）场景下误报 `nicknameMissing` 错误的问题，并确保轮次完成收尾先于下一条排队输入派发执行。
   - 修复跨空间（Cross-Space）Bot 回复未在接收方空间投射完整正文与回复关联的问题，确保跨空间协作消息完整可见。
   - 修复停止流式输出后紧跟派发排队用户消息时的时间线顺序错乱问题，保证实时状态更新与历史恢复中的消息时序一致。
   - 统一过滤反引号包裹的 `` `[PASS]` `` 与裸文本 `[PASS]` 静默标记，避免静默回合标记泄漏到空间路由、流式输出或消息列表中。

2. **工作区上下文、Web 环境兼容与构建链路**
   - 修复开发态 HMR 热更新时工作区 React Context（看板会话、面板动作、代码评审、终端与 Worktree 上下文）丢失的问题。
   - 为非 HTTPS 的局域网或隧道 HTTP Web 访问场景补齐 `crypto.randomUUID` 兼容回退实现，修复非安全上下文下浏览器会话初始化失败的问题。
   - 修复 macOS 发布构建中的 `sccache` 兼容性问题，统一 Sidecar Cargo 特性开关并清理 Linux Clippy 静态检查告警。

### 二、优化

1. **远程连接、外部访问与穿透管理**
   - 统一外部访问、Web 服务、设备配对与 Host 穿透设置界面，重构穿透配置流程为弹窗式新建与连通性校验体验。
   - 已启用穿透时默认展开已保存穿透列表，支持直接启用/停用已保存穿透、记录创建时间，并在保存前提供“测试连通”状态与毫秒级延迟（`ms`）反馈。
   - 在 Web 端与非桌面容器的设置页侧边栏顶部新增“回到主页面”快捷导航入口，并精简 Web 连接引导页（`WebTransportBootstrap`）表单交互。

2. **协作空间草稿、收藏面板与工具卡片体验**
   - 将协作空间输入框未发送草稿（含文本与图片）及各工作区当前选中的会话线程持久化至共享会话存储，切换页面或项目后返回时自动恢复。
   - 协作空间收藏面板中的 Markdown 条目改为默认使用富文本预览视图渲染，并在复制按钮旁新增“在页签中打开”操作以支持直接在工作区页签中查看与编辑。
   - 将 `ask_question` 提问工具卡片固定在回合活动流中的实际调用位置，移除展开态冗余外层容器与重复题干文本；优化项目活动悬浮窗布局并将近期会话标题截断为单行 20 字省略显示。

### 三、新增

1. **工作区 MP4 视频内联预览与预览页签刷新**
   - 工作区 Dockview 预览面板新增 MP4 视频内联播放支持（带 20MB 体积阈值保护，超出时提供打开所在文件夹引导）。
   - 为工作区与协作空间预览页签右键菜单新增“刷新”操作，支持外部文件更新后直接重载当前预览页签内容。

## English

VibeX 0.4.1 refines remote access and host tunnel management, improves collaboration space `@mention` delivery and draft persistence, adds inline MP4 video preview and preview tab refresh, and strengthens runtime stability across web and desktop environments.

### Fixes

1. **Collaboration Space Delivery, Mentions & Turn Stream**
   - Fixed sequential round slots detaching before input dispatch, preserved Bot `@mentions` across open rounds and mid-turn steps, and retried queued inputs during `redeliver_deferred`.
   - Prevented false `nicknameMissing` errors in direct BotSpace chats and sequenced turn completion finalization before dispatching the next queued input.
   - Projected cross-space bot replies into recipient spaces with full message content and reply linkage so cross-space responses remain visible.
   - Preserved chronological ordering of stopped in-flight assistant output before subsequently dispatched queued user turns across live store updates and history recovery.
   - Filtered backtick-enclosed `` `[PASS]` `` silent tokens in addition to bare `[PASS]` markers across space routing, streaming, and message listing.

2. **Workspace Contexts, Web Compatibility & Release Pipeline**
   - Preserved workspace React contexts (`KanbanSessionContext`, `PanelActionsContext`, `ReviewProvider`, `TerminalContext`, and `WorktreeContext`) across Vite HMR updates.
   - Added a `crypto.randomUUID` fallback polyfill for non-HTTPS LAN and tunnel HTTP web origins so browser sessions initialize reliably outside secure contexts.
   - Disabled `sccache` on macOS release builds to avoid caching failures, unified sidecar Cargo feature flags, and resolved Linux Clippy lint warnings.

### Improvements

1. **Remote Access, External Access & Host Tunnel Settings**
   - Unified external access, Web service, device pairing, and host tunnel settings with a modal-based tunnel creation and verification workflow.
   - Expanded the saved tunnel list by default when host tunneling is enabled, added enable/disable toggling and creation timestamps for saved tunnels, and introduced pre-save connectivity testing with live status and latency (`ms`) feedback.
   - Added a "Back to main page" navigation button in the settings sidebar for Web and non-Tauri clients, and streamlined the `WebTransportBootstrap` connection form inputs.

2. **Collaboration Drafts, Collection Panel & Tool Cards**
   - Persisted unsent collaboration space composer drafts (text and images) and per-workspace active thread selections in a shared session-backed store across page and project switches.
   - Rendered Markdown items in the collaboration space collection panel using the rich Markdown preview view instead of raw source text, and added an "Open in tab" action next to the copy button.
   - Anchored `ask_question` tool cards at their invocation position in the turn activity stream without redundant outer wrappers or duplicate prompt text, and refined the project activity hover popover with 20-character single-line title truncation.

### Features

1. **Inline MP4 Video Preview & Preview Tab Refresh**
   - Added inline MP4 video playback in workspace Dockview preview panels with a 20MB size guard and a reveal-in-folder fallback for larger files.
   - Added a context menu `Refresh` action across workspace and collaboration preview tabs to reload open preview tabs after external file updates.

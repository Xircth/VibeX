# VibeX 0.4.2

## 中文

VibeX 0.4.2 带来内置代码补全插件（`vibex.code-completion`）与 Host Monaco 代码编辑器服务桥接、外部目录资源管理器与可迁移数据目录配置、协作空间 Bot 模型与推理强度配置，以及 Agent 进程树清理、Windows 安装器升级与设置中心全面打磨。

### 一、新增

1. **内置代码补全插件与 Monaco 编辑器服务桥接**
   - 新增核心内置插件 `vibex.code-completion`，基于 Host 能力桥接为工作区 Monaco 编辑器提供智能行内代码补全（Inline Completions）与代码编辑器宿主服务（`code-editor` provider service）。
   - 支持在插件中心直接管理与配置代码补全服务，并与工作区预览及编辑面板无缝协同。

2. **外部目录资源管理器、文件预览与数据目录热迁移**
   - 新增外部目录面板（`DockviewExternalDirectoryPanel`），支持在工作区外直接浏览任意本地目录树、打开文件预览及在对话活动流中一键跳转外部目录。
   - 系统设置新增应用数据存储目录（Data Directory）可视化配置与一键迁移能力，支持将运行数据平滑迁移至自定义磁盘路径并在重启后生效。

3. **协作空间 Bot 模型与推理强度动态管理**
   - `manage_bot` 工具与协作空间新增可用 Agent、模型（Model）与思考深度（`thinking_level`）枚举查询，支持在创建或配置 Bot 时直接指定或切换目标模型与推理档位。
   - Markdown 富文本编辑器新增代码块下方的 Mermaid 图表实时预览，编辑源码时即时刷新渲染结果。

### 二、优化

1. **设置中心、外观与版本控制交互重塑**
   - 重构通用设置、外观设置、版本控制（Git / GitHub CLI）、Worktree、远程访问与设备配对页面布局，统一采用紧凑型分段控制器（`SegmentedControl`）与即时生效交互。
   - 外观设置将主题色、缩放与字体归并为基础外观分组，并将看板会话列表视图与看板布局整合为会话看板样式分组；新增破坏性操作按钮（Astryx Soft Red）统一视觉规范。
   - Agent 设置与详情页直接复用状态栏缓存的更新状态徽标，无需等待预检完成即可立即展示可用更新并在点击后即时呈现安装进度。

2. **协作空间、会话组合器与内置浏览器体验**
   - 协作空间将 `ask_user_question` 提问卡片作为独立消息容器渲染，拆分前置正文气泡并去除外层冗余气泡边框；点击进入空间或私聊时立即清除侧边栏未读计数徽标。
   - 会话详情弹窗（`ConversationBundle`）调整 JSON 工作区至会话控制栏下方，提升调试与检视效率。
   - 内置浏览器面板（`HostBrowserPanel`）在导航至新 URL 时自动清理残留冻结帧，并在切换至看板或插件页签时自动停靠原生视图（Native Surface Handoff），确保浮层与工具提示不被遮挡。

### 三、修复

1. **Agent 生命周期、进程树清理与安装器可靠性**
   - 修复 Agent 连接断开或应用退出时子进程残留的问题，统一清理完整进程树；自动自愈陈旧的“正在连接”提示，并避免外部二进制文件触发归档 SHA-256 校验冲突。
   - 修复 Windows 平台 `cmd /c` 执行含空格路径批处理脚本失败及本地代码页（Codepage）输出乱码问题；修复 GitHub CLI 在 Windows 下的终端登录命令引号转义与双层压缩包解压问题。
   - 修复 Windows 安装器在安装或自动更新时未终止伴随进程的问题，并在应用内更新时完整呈现自定义安装界面；改进 WebView2 用户数据目录独占锁检测与自动回收机制。
   - 修复监控用户主目录时的文件系统监听器性能问题，自动跳过 `AppData` 与系统缓存目录；为多实例挂载下的异步 Agent 安装失败通知去重。

## English

VibeX 0.4.2 introduces the built-in `vibex.code-completion` plugin with a host Monaco code-editor service bridge, an external directory explorer and configurable data directory migration, bot model and thinking level configuration in collaboration spaces, and comprehensive improvements to agent process tree cleanup, Windows installer updates, and settings UX.

### Features

1. **Built-in Code Completion Plugin & Monaco Code-Editor Service Bridge**
   - Added the built-in `vibex.code-completion` plugin powered by the host `code-editor` provider service bridge to deliver inline completions in workspace Monaco editors.
   - Integrated plugin lifecycle and configuration controls with workspace preview and editor panels.

2. **External Directory Explorer, File Preview & Data Directory Migration**
   - Added `DockviewExternalDirectoryPanel` to browse external directories outside the current workspace, preview external files, and jump to external folders directly from turn activity items.
   - Added configurable application data directory settings with guided migration in System Settings.

3. **Collaboration Bot Model & Thinking Level Configuration**
   - Extended `manage_bot` and collaboration roster APIs to list available agents, models, and thinking levels, and to configure a bot's `model` and `thinking_level` directly.
   - Added live Mermaid diagram previews beneath `mermaid` code blocks in the Markdown rich-text editor that update automatically on edits.

### Improvements

1. **Settings Center, Appearance & Version Control Overhaul**
   - Redesigned General, Appearance, Version Control (Git / GitHub CLI), Worktree, Remote Access, and Device Pairing settings with immediate `SegmentedControl` interactions and unified control geometry.
   - Grouped theme accent, zoom, and font under basic appearance settings, consolidated Kanban session list and board layout under session board style, and standardized destructive button styling.
   - Surfaced cached agent update badges immediately in Agent Settings and Agent Detail before preflight checks finish, and displayed live progress immediately upon starting an operation.

2. **Collaboration Space, Conversation Bundle & Host Browser Polish**
   - Rendered `ask_user_question` cards as standalone containers outside member message bubbles while keeping preceding prose in its own bubble, and cleared unread badges immediately when selecting a space or DM.
   - Positioned the JSON workspace below conversation controls in the `ConversationBundle` modal.
   - Cleared active freeze-frames when navigating to a new URL in `HostBrowserPanel` and parked native browser surfaces when switching to Kanban or plugin tabs to prevent overlay occlusion.

### Fixes

1. **Agent Process Tree Cleanup, Windows Compatibility & Installer Reliability**
   - Cleaned up full agent process trees on disconnect and exit, self-healed stale connecting notices, and avoided archive SHA-256 mismatches on externally reconciled binaries.
   - Preserved spaced batch script paths under Windows `cmd /c`, decoded local codepage process output, and fixed Windows quote escaping and archive extraction for GitHub CLI login and installation.
   - Stopped companion processes during Windows install and update flows, rendered the custom NSIS installer UI on app updates, and hardened WebView2 user-data lock detection and reclamation.
   - Skipped `AppData` and system cache directories when watching user profile roots, and deduplicated asynchronous agent installation failure notifications across mounted hook instances.

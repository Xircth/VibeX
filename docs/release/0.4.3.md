# VibeX 0.4.3

## 中文

VibeX 0.4.3 带来全新 AI 语音输入插件（`vibex.voice-input`）、原生 OMP（Oh My Pi）ACP 智能体接入、1800+ 原生连接器市场（Connector Marketplace）与智能 MCP 解析器、SwiftUI iOS 伴随应用（Companion App）与设备配对升级、工作区标签组与堆叠标签交互重塑，以及代码补全、技能市场与多智能体协作空间的全面增强。

### 一、新增

1. **AI 语音输入插件（`vibex.voice-input`）**
   - 新增官方内置插件「语音输入」（`vibex.voice-input`），支持按住说话与快捷键触发语音录入、流式语音识别转写与 AI 润色。
   - 支持交互式词元胶囊（Token Pills）管理自定义专业词汇热词，提供状态栏快捷开关弹窗与遵循 VibeX 视觉规范的自定义下拉选择器。

2. **原生 OMP（Oh My Pi）ACP 智能体接入**
   - 新增 OMP 作为内置原生 ACP 智能体，支持自动引导受管 Bun 运行时完成安装与预检修复。
   - 支持 OMP 原生 `approvalMode` 配置与会话级 YOLO 模式切换、OAuth 账号状态解析，以及 Linux `musl` 架构的 ACP Registry 目标识别。

3. **1800+ 原生连接器市场与智能 MCP 解析器**
   - 内置 1800+ 连接器目录（Connector Marketplace），提供状态栏商店快捷弹窗、分类计数浏览与双模式 MCP 设置页面。
   - 状态栏 MCP 弹窗实时展示已连接的本地 MCP 服务器与连接器，并自动发现与列出可用工具列表。

4. **SwiftUI iOS 伴随应用与分类设备配对**
   - 新增基于 `CompanionCore` 的原生 SwiftUI iOS 伴随应用，支持实时活动（Live Activity）进度跟踪与只读工作区/项目 API 访问。
   - 设备配对面板新增连接设备类型选择预设，且配对完成后自动保持远程服务（Remote Service）持续运行。

5. **技能排行榜与双栏详情视图**
   - 技能（Skills）设置页与 MCP 设置页默认打开市场标签页，新增技能排行榜（Leaderboard）及双栏 `SKILL.md` 详情预览视图。

### 二、优化

1. **工作区标签组、文件树搜索与会话列表打磨**
   - 升级工作区会话标签组（Tab Groups）、堆叠式标签页、四分类新建菜单以及 32 字符会话标题上限。
   - 优化文件树搜索过滤、会话列表排序与原生标题工具提示（Tooltip）宿主交互，改进协作空间消息投递与展示体验。

2. **代码补全引擎（`vibex.code-completion`）全面进化**
   - 集成 `monacopilot` 补全引擎，支持任意光标位置触发、光标空闲自动触发、可编辑手动触发快捷键与状态栏配置弹窗。
   - 自动在推理模型上禁用思考链以降低首字延迟，保留闭合分隔符后缀与多行缩进对齐，支持基于已保存凭据自动探测模型列表。

### 三、修复

1. **连接自愈、插件沙箱与桌面宿主稳定性**
   - 修复智能体连接断开（`agent_connection_lost`）时的死连接驱逐与会话自动恢复，并将错误卡片准确映射为连接关闭状态。
   - 修复 `vibex.code-completion` 行内触发缓存死锁、方法边界截断、输入防抖竞争与热重载单例清理问题，使插件 Worker 产物完全自包含并遵循 `ADR-0069` 无特权原则。
   - 修复 `computer-use` 插件在弹窗中“整个屏幕”选择器下拉菜单被裁切的问题，并同步屏幕共享状态。
   - 修复桌面端预览服务回环地址（Loopback `previewUrl`）暴露、项目 `root_path` 迁移去重、Windows WebView2 配置目录回退及技能卸载清理。

## English

VibeX 0.4.3 introduces the built-in AI Voice Input plugin (`vibex.voice-input`), native OMP (Oh My Pi) ACP agent integration, a 1,800+ native Connector Marketplace with smart MCP parsing, a SwiftUI iOS Companion app with device-type pairing presets, upgraded workspace tab groups and stacked tabs, and extensive refinements to inline code completion, the Skills Marketplace, and multi-agent collaboration.

### Features

1. **AI Voice Input Plugin (`vibex.voice-input`)**
   - Added the official built-in Voice Input plugin (`vibex.voice-input`) with push-to-talk and shortcut recording, speech-to-text transcription, and AI post-processing.
   - Added interactive token pills for custom vocabulary hotwords, a streamlined status bar switch popover, and custom VibeX dropdown selectors.

2. **Native OMP (Oh My Pi) ACP Agent Integration**
   - Added OMP as a first-class built-in ACP agent with managed Bun runtime bootstrapping for installation and preflight repair.
   - Added support for OMP native `approvalMode` and session YOLO mode, OAuth account label resolution, and Linux `musl` ACP Registry targets.

3. **1,800+ Native Connector Marketplace & Smart MCP Parser**
   - Integrated a 1,800+ native Connector Marketplace with a status bar store popover, full catalog browsing with category counts, and dual-mode MCP settings.
   - Added live tool discovery and connected server/connector inspection directly in the status bar MCP popover.

4. **SwiftUI iOS Companion App & Device Pairing Presets**
   - Added the native SwiftUI iOS Companion app powered by `CompanionCore` with Live Activity progress tracking and read-only workspace and project APIs.
   - Added device-type selection when pairing a new device and kept the Remote service running automatically after pairing completes.

5. **Skills Leaderboard & Dual-Column Detail View**
   - Defaulted both MCP and Skills settings pages to the Marketplace tab, and added a Skills Leaderboard alongside a dual-column `SKILL.md` detail view.

### Improvements

1. **Workspace Tab Groups, File Tree Search & Session List Polish**
   - Upgraded session tab groups, stacked tabs, a 4-category add menu, and a 32-character session title cap.
   - Refined file tree search filtering, session list ordering, native title tooltip hosting, and collaboration space message delivery.

2. **Code Completion Engine (`vibex.code-completion`) Upgrades**
   - Integrated `monacopilot` completion registration with cursor-idle auto-triggering, completion at arbitrary cursor positions, configurable manual trigger shortcuts, and a status bar configuration popover.
   - Disabled reasoning on thinking models for lower latency, preserved closing delimiter suffixes and multi-line indentation alignment, and added model discovery using saved credentials.

### Fixes

1. **Connection Recovery, Plugin Sandboxing & Desktop Host Stability**
   - Evicted dead connections and auto-recovered sessions on `agent_connection_lost`, mapping the error card state to `connection_closed`.
   - Fixed inline completion trigger cache deadlocks, method-boundary stop truncation, typing idle-trigger races, and singleton reload cleanup while making worker bundles self-contained under `ADR-0069` (`plugin:no-privilege`).
   - Fixed dropdown clipping for the "Entire Screen" selector in the `computer-use` popover and synchronized screen-share state.
   - Fixed loopback `previewUrl` exposure on desktop transport, deduplicated project `root_path` migrations, added Windows WebView2 profile fallback, and hardened skill removal.

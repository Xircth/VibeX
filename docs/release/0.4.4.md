# VibeX 0.4.4

## 中文

VibeX 0.4.4 带来端到端加密（E2EE）远程连接与云端中继支持、Android 伴随应用（Companion App）与 iOS 1:1 体验对齐、应用数据目录（Data Directory）无损自动收养与迁移、多智能体协作空间消息投递与交互卡片全面升级，以及 ACP 智能体外部运行时适配与语音输入插件的深度打磨。

### 一、新增

1. **端到端加密（E2EE）远程连接、云端服务与移动设备连接横幅**
   - 新增远程连接端到端加密（E2EE）与 WebRTC 安全会话传输协议，支持设备密钥绑定、幂等校验与设备连接请求审批。
   - 新增云端隧道服务支持与桌面端移动设备连接提醒横幅（`MobileDeviceConnectBanner`），大幅简化跨网段与移动端配对连接流程。

2. **Android 伴随应用 1:1 对齐 iOS 体验**
   - 新增并升级 `mobile/android` 伴随应用子模块，实现与 iOS 伴随应用 1:1 的 UI 组件、会话时间线、首条指令发送及 `plugin.read` 权限对齐。

3. **插件依赖自动安装与条件化配置表单**
   - 激活插件时自动解析、安装并启用其声明的必需依赖插件，消除手动前置安装步骤。
   - 插件 JSON Schema 设置表单与 `vibex.voice-input` 新增 `x-visible-when` 条件字段显隐支持，在本地识别协议下自动隐藏无关云端 API 配置项。

### 二、优化

1. **协作空间投递引擎、交互卡片与对话时间线重塑**
   - 升级协作空间消息投递与回执管线，为每次 MCP 工具调用与实例生成独立作用域的 `operation_id`，避免多 Bot 并发发言冲突。
   - 优化协作卡片、流式对话时间线（`ConversationTimeline`）与 `ask_user_question` 提问交互模型，改进工作区会话列表工具栏与分支选择体验。

2. **语音输入（`vibex.voice-input`）与内置浏览器插件体验升级**
   - 增强语音输入插件本地与混合语音识别工作流、状态反馈及快捷键交互，优化内置浏览器宿主服务与 Worker 稳定性。

### 三、修复

1. **数据目录（Data Directory）自动收养与防遮蔽保护**
   - 修复升级或重装后安装目录下新建空数据库遮蔽原有 Roaming 数据目录的问题：启动时自动比对并收养数据更完整的数据库，保留被替代副本（`.superseded-<stamp>`），并自动重写数据库、`settings.json` 与 Git Worktree 路径。
   - 切换数据目录至已包含 VibeX 数据库的目录时直接挂载已有数据，避免覆盖历史记录。

2. **ACP 智能体外部运行时参数与长连接自愈**
   - 修复外部安装的 `opencode`、`openclaw`、`cline`、`codebuddy`、`kimi`、`grok`、`cursor-agent` 等 CLI 在探测与启动 ACP 会话时缺失子命令参数（如 `acp` / `--acp` / `agent stdio`）的问题。
   - 修复 Antigravity 等智能体在后台任务挂起并发送 WebSocket `1000 (OK)` 正常关闭帧时被误判为异常断连的问题，确保回合平稳结束。
   - 修复协作空间在紧凑模式下新建群组/Bot 弹窗无法打开的问题。

## English

VibeX 0.4.4 introduces end-to-end encrypted (E2EE) remote connections with cloud relay support, 1:1 iOS UI parity for the Android Companion app, automatic lossless data directory adoption and migration, upgraded multi-agent collaboration delivery and interactive cards, and broad ACP agent runtime and Voice Input refinements.

### Features

1. **End-to-End Encrypted (E2EE) Remote Connections, Cloud Relay & Mobile Connect Banner**
   - Added end-to-end encryption (`e2ee`), WebRTC transport session security, device key binding, and device connection request approvals for remote access.
   - Added cloud service relay support and `MobileDeviceConnectBanner` on the desktop shell to streamline mobile device pairing and connection handshakes.

2. **Android Companion App with 1:1 iOS Parity**
   - Extracted and updated the `mobile/android` companion submodule to reach 1:1 UI parity with the iOS Companion app, including conversation timelines, initial prompt submission, and `plugin.read` scope support.

3. **Automatic Plugin Dependency Installation & Conditional Settings Forms**
   - Automatically installs and enables required plugin dependencies when activating a plugin.
   - Added `x-visible-when` conditional field visibility to `PluginSchemaSettingsForm` and `vibex.voice-input` so cloud API fields stay hidden when using local speech recognition protocols.

### Improvements

1. **Collaboration Delivery Pipeline, Interactive Cards & Timeline Streaming**
   - Scoped MCP `operation_id` generation per tool invocation and companion instance in `vibex-mcp` to prevent collisions across concurrent bot messages.
   - Refined collaboration cards, `ConversationTimeline` streaming rhythm, `ask_user_question` prompt models, workspace session list toolbars, and branch option selectors.

2. **Voice Input (`vibex.voice-input`) & Host Browser Polish**
   - Enhanced local and hybrid dictation workflows, status feedback, and shortcut handling in `vibex.voice-input`, alongside host browser service and worker stability improvements.

### Fixes

1. **Data Directory Adoption & Shadowing Prevention**
   - Fixed a defect where a newly created `<install_dir>/data` database could shadow an existing Roaming database after an upgrade: Desktop and `vibex-server` now automatically adopt the larger database into the install directory, preserve any superseded database as `*.superseded-<stamp>`, and rewrite stored paths and Git worktrees.
   - Switching the data directory to a folder that already contains a VibeX database now opens it in place instead of overwriting it.

2. **ACP External Runtime Arguments & Session Turn Completion**
   - Added required ACP launch subcommands (`acp`, `--acp`, `agent stdio`) to external runtime candidates for `opencode`, `openclaw`, `cline`, `codebuddy`, `kimi`, `grok`, and `cursor-agent`.
   - Treated Antigravity WebSocket `1000 (OK)` turn-suspension close messages after visible output as clean turn completions rather than connection errors.
   - Fixed collaboration space create dialogs not opening when triggered outside a full runtime subscription.

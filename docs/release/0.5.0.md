# Dimo 0.5.0

## 中文

Dimo 0.5.0 是项目由 VibeX 正式更名为 Dimo 后的首个里程碑版本。本次发布围绕 **Pulse 事件驱动自动化引擎与双原语 Workflow Studio**、**可插拔原生 Agent 运行时与跨 Agent 续写/分叉（Handoff & Fork）**、**账号中心与官方 ModelRouter 网关**、**无限画布多模态工作台** 以及 **全链路性能与稳定性重塑**，全面重构桌面端与 Server 端研发协作体验。

### 一、新增

1. **品牌升级：VibeX 正式更名为 Dimo**
   - 完成全仓、CLI / npm 包（`@dimoai/dimoai`、`@dimoai/plugin-sdk`）、`dimo-server`、`dimo-mcp`、`dimo-workflow-mcp`、Tauri 桌面应用及 CI/CD 发行管线向 **Dimo** 品牌的完整迁移与数据平滑收养。

2. **Pulse 事件引擎与双原语 Workflow Studio**
   - 引入全新的事件驱动自动化内核 `crates/pulse`（支持 Webhook、GitHub/Jira/飞书等事件连接器、Cron 定时调度、条件过滤评估器、Dry-Run 试运行与事件 Outbox 回执投递）。
   - 推出可视化的 **Workflow Studio** 编排工作台与 `dimo-workflow-mcp` 工具集，支持在 DAG 中混合编排一次性 `Session` 节点与持久化 `Bot` 节点，涵盖 `BoundedLoop`、`WaitForEvent`、`UserGate`（人工审批门禁）与 `OutboxAction`，并内置 4 套开箱即用的自动化模板。
   - 看板与工作区入口升级为 Agent 优先的双标签自动化工作台（`PulseDeckView`），顶部状态栏直接承接待审批操作与自动化触发状态。

3. **可插拔 `NativeEngineDriver`、多实例 Agent 与跨 Agent 续写分叉**
   - 正式化插件化的 `NativeEngineDriver` 原生驱动架构，原生支持 Claude Code、Codex、Grok、DeepSeek Harness 等多类智能体运行时，支持内置模型目录（Provider Presets）与自定义模型配置。
   - 新增 **多实例（Provider Instances）** 隔离管理与切换器（`AgentInstanceSwitcher`），同一智能体可同时维护多套独立认证与端点实例（支持无密钥局域网端点与旁路代理）。
   - 新增 **跨 Agent 会话交接与内联分叉（Engine Handoff & Fork）**，支持在对话回合之间无缝切换目标 Agent、生成历史摘要上下文并保留 `ContextHandoffDivider` 分割锚点。
   - 新增 **Side Chat** 侧边并发轻量对话窗格与 **限流自动恢复横幅（`RateLimitRecoveryBanner`）**。

4. **Dimo 账号中心、订阅用量与云端配置同步**
   - 新增 **账号中心（Account Settings）**，统一管理登录设备、Host 绑定状态、订阅套餐与用量仪表盘（`PlanUsageDashboard`），并支持多台远端 Host 配置的云端同步与官方单节点云中继租约。
   - 打通桌面端智能体设置与官方 **ModelRouter 模型市场**，一键同步 20+ 主流网关兼容智能体配置与深度链接（Deep-link）导入。

5. **无限画布工作台（Infinite Canvas）与内置浏览器凭据保险箱**
   - 全工作区标签页接入无限画布节点体系，支持自由分组、四向连线、3D Stage Dock 视口切换、从文件树拖拽落盘创建节点以及跨面板撤销/重做历史。
   - 内置浏览器新增本地加密 **凭据保险箱（Credential Vault）**、地址栏高频历史智能建议以及主流浏览器配置文件与用户数据一键导入。

### 二、优化

1. **全链路性能治理与前端首屏瘦身**
   - 对后端对话投影（Projection Single Authority）、SQLite 事务写入、事件广播通道与原生 Sidecar 监听生命周期进行系统性重构，消除高频轮询与锁竞争。
   - 前端将事件通道按作用域收敛、分离高频流式渲染与状态动作 Context，并将语言包拆分为按需异步加载 Chunk，显著降低首屏 Bundle 体积与流式输出卡顿。
   - 优化 Markdown 闭合块 LRU 缓存、KaTeX 公式懒加载与流式代码高亮延迟编译，长对话流式渲染更顺滑。

2. **统一视觉设计系统与交互打磨**
   - 全面落地 `--type-*` 七阶字体层级与主题自定义色板（含内置 `ayu-theme` 主题插件及用户自定义配色）。
   - 统一工作区标签栏（Dockview）分栏宽度再平衡与切角材质、优化全局电源搜索（Power Search）、会话草稿箱暂存（Draft Stash）与实时引导（Basic Guide）体验。

### 三、修复

1. **原生引擎流式去重与会话生命周期自愈**
   - 修复 Claude / Codex 原生流式帧重复投递与 Live Overlay 修订覆盖问题，清理孤儿 Sidecar 监听句柄，确保回退（Rewind）与中断重启后会话状态一致。
   - 修复 MCP 服务列表残留旧版条目、模型别名识别以及多 Provider 共存时的配置隔离问题。

2. **插件安装迁移与跨平台宿主兼容性**
   - 加固 Dimo 品牌升级后的插件迁移、自动隔离恢复（Auto-Quarantine）与热配置更新机制，修复 Windows Worktree 开发环境下 Tauri 单实例锁与 UserData ACL 冲突。
   - 修复画布撤销/重做历史断点、嵌套坐标系偏移及高 DPI/分栏拖拽边界异常。

## English

Dimo 0.5.0 marks our first milestone release following the official rebrand from **VibeX** to **Dimo**. This release delivers the **Pulse Event-Driven Automation Engine & Dual-Primitive Workflow Studio**, **Pluggable Native Engine Drivers with Multi-Instance Agents & Cross-Agent Handoff/Fork**, **Dimo Account Center & Official ModelRouter Gateway**, an upgraded **Infinite Canvas Workspace**, and **end-to-end performance & reliability hardening** across desktop and server.

### Features

1. **Official Rebrand: VibeX → Dimo**
   - Completed full brand migration across the desktop client, `dimo-server`, `dimo-mcp`, `dimo-workflow-mcp`, npm/CLI packages (`@dimoai/dimoai`, `@dimoai/plugin-sdk`), and CI/CD release pipelines, with seamless local data adoption.

2. **Pulse Event Engine & Dual-Primitive Workflow Studio**
   - Introduced `crates/pulse`, an event-driven automation engine featuring webhook/connector intake (GitHub, Jira, Feishu, and custom SDK events), Cron scheduling, client/server filter evaluators with dry-run testing, and reliable outbox delivery.
   - Added visual **Workflow Studio** and `dimo-workflow-mcp` tools supporting dual-primitive DAG composition (mixing ephemeral `Session` nodes and persistent `Bot` nodes) with `BoundedLoop`, `WaitForEvent`, `UserGate` human approvals, `OutboxAction`, and 4 built-in canonical templates.
   - Launched the Agent-first automation workbench (`PulseDeckView`) alongside StatusBar approval indicators.

3. **Pluggable `NativeEngineDriver`, Multi-Instance Agents & Cross-Agent Handoff/Fork**
   - Formalized `NativeEngineDriver` architecture for native Claude Code, Codex, Grok, and DeepSeek Harness runtimes with built-in provider preset catalogs and custom model definitions.
   - Added **Provider Instance Switching** (`AgentInstanceSwitcher`) so each agent supports multiple isolated credential/endpoint profiles, including keyless LAN endpoints and proxy bypass.
   - Added **Cross-Agent Handoff & Inline Fork** (`ContextHandoffDivider`) to transfer context cleanly between agents mid-conversation or branch into a new target agent.
   - Added **Side Chat** for lightweight parallel queries and **Rate-Limit Recovery Banner** (`RateLimitRecoveryBanner`).

4. **Dimo Account Center, Subscription Usage & Cloud Host Sync**
   - Added **Account Settings** unifying device bindings, `PlanUsageDashboard`, subscription credits, saved remote Host config sync across devices, and single-node cloud relay leases.
   - Integrated **ModelRouter Marketplace** directly into desktop Agent settings with one-click deep-link import across 20+ gateway-compatible agents.

5. **Infinite Canvas Workspace & Host Browser Credential Vault**
   - Unified all workspace tabs into Infinite Canvas nodes with 4-side connectors, Stage Dock switching, drag-and-drop creation from the file tree, and multi-step undo/redo history.
   - Added an encrypted local **Credential Vault**, browser profile/user-data import, and frequency-ranked omnibox suggestions in the built-in Host Browser.

### Improvements

1. **End-to-End Performance & Startup Bundle Optimization**
   - Consolidated conversation projection authority, eliminated SQLite write amplification and background polling loops, and bounded runtime caches across `conversations`, `agents`, and `server`.
   - Scoped frontend event channels, separated streaming state contexts, and split i18n locale bundles into lazy-loaded chunks to shrink initial startup JS overhead.
   - Improved closed-block Markdown LRU caching, lazy KaTeX rendering, and deferred code-block highlighting during live streaming.

2. **Unified Design Tokens & Ergonomics**
   - Standardized the 7-step `--type-*` typography ramp, user/plugin theme customization (including the built-in `ayu-theme` plugin), balanced Dockview column splitting, Power Search, Draft Stash, and interactive Basic Guide onboarding.

### Fixes

1. **Native Stream Deduplication & Session Lifecycle Recovery**
   - Fixed duplicate native Claude/Codex stream frames, live overlay revision overwrites, and orphaned sidecar listener leaks across turn rewinds and restarts.
   - Cleaned up legacy MCP catalog entries and hardened multi-provider model alias resolution and steering delivery.

2. **Plugin Migration, Canvas History & Cross-Platform Host Stability**
   - Hardened Dimo plugin migration, auto-quarantine recovery, and hot config updates (`Volatile<T>`), plus Windows worktree dev isolation for Tauri single-instance and ACL paths.
   - Fixed Infinite Canvas undo/redo history gaps, nested group coordinate transforms, and Dockview split resize bounds.

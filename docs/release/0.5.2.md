# Dimo 0.5.2

## 中文

Dimo 0.5.2 聚焦官方域名与插件市场迁移、同账号移动设备无缝连接与 TLS 443 云中继、开发者模式记忆开关、界面交互与滚动画布打磨，以及启动数据库读写隔离与安全边界加固。

### 一、新增

1. **官方域名迁移与插件更新回退兼容**
   - 官方站点、插件市场与云中继默认指向 `https://dimo-ai.com`，ModelRouter 官方网关写入使用 `https://model.dimo-ai.com`；同时继续兼容已保存的提供方、中继分配及历史 `vibex.xforever.xin` 来源配置。
   - 插件更新器会自动归一化旧版市场源地址、在需要时回退至官方 GitHub Releases，并清理旧版本宿主遗留的失效更新失败缓存。

2. **同账号移动伴侣无感直连与云中继 TLS 443 升级**
   - 同一账号下已登录的移动设备支持无点击自动连接，新增配对信标发现，并在宿主退出登录时自动吊销关联设备授权。
   - 云中继连接支持 TLS 443 握手升级探测，并对租约续期请求进行去重。

3. **系统设置记住开发者模式开关与统一输入面板**
   - 正式版可在「系统设置」中开启或关闭开发者模式（持久化保存于本地 `settings.json`），关闭时拦截 `F12` 与 `Ctrl+Shift+I` 避免调试快捷键残留。
   - 新增统一底部输入扩展坞（`ComposerTabDock`）与平滑选项高亮菜单（`GlideMenu`）。

### 二、优化

1. **协作长对话、画布缩放与界面细节**
   - 协作空间长对话支持按窗口向后分页加载与渲染优化，减少超长会话滚动卡顿。
   - 采用贴边悬浮滚动条（不再挤占内容区布局宽度），并统一工作区分栏为单条分割线。
   - 无限画布支持按住修饰键配合滚轮缩放；本地历史记录支持在后台静默导入，并在底部状态栏实时显示导入进度。
   - 优化工具询问卡片、消息队列指示器与子智能体状态卡片的视觉与交互细节。

2. **智能体运行时、代理感知镜像与故障诊断**
   - 内置运行环境下载（Node、npm、uv 等）支持代理感知：检测到活跃代理时优先官方源，否则优先国内镜像源并自动回退。
   - OMP 智能体模型选择器的选项标签自动带上 `provider/model` 前缀以便区分；完善 Grok 原生提供方配置与 Kimi 退出登录后的本地认证清理。
   - 对话时间线中的终端命令执行失败会显示退出码；应用更新面板增强了错误诊断与手动下载引导；文档新增智能体与协作故障排查指南（`docs/agents/troubleshooting.md`）。

### 三、修复

1. **启动性能、Windows 数据库收养与对话投影边界**
   - 事件流快照改走独立只读连接池（`ReadPool`），降低并发读写锁竞争；加固 Windows 端 SQLite 数据目录迁移与路径重映射（含 `\\?\` 长路径前缀与异常状态修复）。
   - 对话投影准确跟踪并折叠被拒绝的工具调用状态，细化协作角色权限与宿主浏览器面板尺寸边界。

2. **安全边界与跨进程通信加固**
   - 收紧应用 CSP 策略与 Tauri 权限能力清单，加固 E2EE 与 WebSocket 传输校验、计算机控制 RPC 及插件运行时隔离边界。

## English

Dimo 0.5.2 migrates official origins to `dimo-ai.com`, adds zero-click companion connect with TLS 443 cloud relay support, introduces a remembered Developer Mode toggle, polishes collaboration, canvas, and timeline UI, and hardens startup SQLite isolation and host security boundaries.

### Features

1. **Official `dimo-ai.com` origins and plugin update fallback**
   - The official site, plugin marketplace, tunnel defaults, and documentation now target `https://dimo-ai.com`, while ModelRouter gateway writes use `https://model.dimo-ai.com`. Saved providers, relay assignments, and legacy `vibex.xforever.xin` origins continue to work seamlessly.
   - The plugin updater normalizes legacy marketplace origins, falls back to official GitHub releases when needed, and clears stale failed-update records from older host versions.

2. **Seamless companion auto-connect and TLS 443 cloud relay**
   - Devices signed into the same account can connect without manual approval clicks, announce via a pairing beacon, and are automatically revoked when the host signs out.
   - Cloud relay connections support TLS 443 upgrade probing and deduplicate lease renewal requests.

3. **Remembered Developer Mode switch and unified composer dock**
   - Release builds expose a remembered Developer Mode toggle in System Settings (`settings.json`) to open or close the webview inspector, swallowing `F12` and `Ctrl+Shift+I` cleanly when disabled.
   - Added a unified `ComposerTabDock` and `GlideMenu` option highlight animation.

### Improvements

1. **Collaboration long-chat paging, canvas zoom, and layout polish**
   - Long collaboration space conversations paginate backward smoothly and optimize rendering performance.
   - Overlay scrollbars stay flush against panel edges without shifting layout width, and Dockview splits render a single clean divider line.
   - The Infinite Canvas supports modifier-key wheel zoom, and local session history imports quietly in the background with status bar progress.
   - Refined the visual styling and interactions of `AgentQuestionCard`, `MessageQueueIndicator`, and `SubagentCard`.

2. **Agent runtime, proxy-aware mirrors, and diagnostics**
   - Managed toolchain downloads (Node, npm, uv) now order official registries first when an active proxy is detected and mirrors first otherwise, with automatic fallback.
   - OMP model picker choices are qualified with `provider/model` labels; updated Grok native provider configuration and Kimi local credential cleanup on logout.
   - Terminal command failures now display exit codes in the timeline, the App Updater shows clearer error diagnostics and a manual download link, and `docs/agents/troubleshooting.md` documents verified agent recovery steps.

### Fixes

1. **Startup read pooling, Windows SQLite adoption, and projection accuracy**
   - Event stream snapshots read through the dedicated `ReadPool` to avoid write-lock contention, and Windows SQLite data-directory adoption/migration handles verbatim `\\?\` path prefixes and healing guards more reliably.
   - Conversation projection accurately tracks denied tool calls, and collaboration roles and host browser surface bounds are hardened.

2. **Security and transport hardening**
   - Tightened Content Security Policy (CSP), Tauri capabilities, E2EE/WebSocket transport checks, computer-use RPC validation, and plugin boundary isolation.

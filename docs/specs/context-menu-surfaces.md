# 产品右键菜单规格

状态：已落地（全局拦截 + 各表面产品菜单）
范围：桌面 Host 的 Server-bound window（工作区、首页、设置、插件、工作流）。远程 Web 客户端同一套命中规则；CEF 浏览器内容页除外，见「浏览器预览」。

---

## 1. 问题

Tauri WebView 在空白处右键会弹出系统/Chromium 菜单（macOS 常见为 Back、Reload、Inspect Element）。这是浏览器壳，不是产品。目标：

1. 产品内永远不出现原生浏览器菜单。
2. 有明确操作的表面弹出产品菜单；没有操作的表面吞掉右键。
3. 菜单项只复用已有按钮、命令或薄 Host 能力（导出文件、写剪贴板、滚动），不借此引入新子系统。

---

## 2. 原则

- **先命中、再决定。** 右键先判定目标（条目 / 空白 / 可编辑 / 禁区），再决定菜单或静默。
- **一条动作一个入口。** 菜单调用与工具栏、行内按钮、快捷键同一函数；禁止平行实现。
- **空白菜单管「这个面」，条目菜单管「这个对象」。** 不要把对象操作塞进空白菜单。
- **有选区时优先处理选区。** 选中文本时，菜单第一项是复制选区，再分隔线，再表面菜单。
- **可编辑控件走编辑菜单。** `input` / `textarea` / `contenteditable` / Composer 为剪切、复制、粘贴；不叠加表面菜单。
- **禁区不弹产品菜单。** 终端为保护右键粘贴；系统对话框、toast、加载遮罩、标题栏交通灯区域不弹菜单。
- **空菜单也不露原生壳。** 禁区或无动作时 `preventDefault`，不显示任何项。
- **文案用产品词。** Conversation 称「会话」；不写 IPC、bundle、Dockview 等实现名。

## 4. 全局策略

桌面 WebView 在 `document` 上统一监听 `contextmenu`：

1. 一律 `preventDefault`，禁止 Back / Reload / Inspect Element。
2. 按命中表决定：产品菜单 / 编辑菜单 / 静默。
3. macOS Control-click、触控板双指点按与右键同一路径。
4. 已打开的产品菜单再右键：先关旧菜单，再按新命中打开。
5. 点击空白、失焦、Escape、滚动、窗口 resize 关闭菜单。
6. Monaco 自带菜单、xterm 自带菜单都不得露出浏览器壳。文件预览用产品菜单覆盖 Monaco 默认菜单；终端见第 8.4 节，不弹产品菜单。

视觉：沿用现有 `tahoe-popover` / 文件树菜单（圆角、毛玻璃、约 220px 宽、分组分隔线、子菜单向右展开）。不新增第二套菜单组件语义。

---

## 5. 命中优先级

从内到外，命中即停：

1. **禁区** — 终端面板、原生 CEF 页面内部（由浏览器面自己的菜单接管）、系统对话框、toast、拖拽中、模态确认。
2. **可编辑** — 输入框、文本域、Composer、contenteditable。
3. **对象** — 文件节点、会话行/卡片、Git 文件/提交、插件行、工作流节点、项目行等。
4. **表面空白** — 该面板剩余客户区。
5. **壳层** — 工具栏、状态栏、活动栏、项目栏空白、Dock 标签栏空白。默认静默；标签本身可有关闭菜单。
6. **选区补丁** — 若 2–4 命中且窗口有非折叠选区，菜单顶部插入「复制」。

未命中任何产品面时仍拦截原生菜单（静默）。

---

## 6. 能力来源约定

每个菜单项必须能指到现有函数。允许的「薄 Host」仅限：

- 剪贴板写入（`writeClipboardViaBridge` / `navigator.clipboard`）
- 保存对话框 + 写文件（已有 `exportConversation` 的 Tauri `save` / `writeTextFile`）
- 选目录后批量写多个 `.md`（循环已有 `conversation_export_markdown`）
- 滚动到顶/底（已有 `scrollToBottom`、Monaco `revealLine`、元素 `scrollTop`）
- 图片另存为（已有预览字节 + 保存对话框）

禁止：新的导出格式协议、新的排序模型、新的会话包 schema、为右键单独做权限/网络能力。

### 7.3 会话执行区（Conversation panel）

含右侧固定会话列、拖到编辑区的会话面板、看板执行槽里的同一时间线。Composer 与时间线分开命中。

**时间线空白 / 面板背景（非消息气泡、非 Composer）**

| 项 | 策略 | 来源 |
|---|---|---|
| 导出会话 | 接线 | `exportConversation(id, 'markdown' \| 'html')`。菜单两项：导出为 Markdown、导出为 HTML（与会话行现有导出一致） |
| Fork 本会话 | 接线 | `conversationApi.fork(conversationId)`，成功后 `placeCreatedSession` / `placeForkedChild` |
| 复制会话内容为 Markdown | 薄 Host | `conversationApi.exportMarkdown` + 剪贴板 |
| 创建新会话 | 接线 | `requestCreateSession` / `RightPanelNewSessionPrompt` |

无会话时只保留「创建新会话」。Fork 在 Agent 不支持 `fork_session` 时禁用，理由沿用现有 toast。

**时间线消息 / Turn（对象）**

不另做一套重菜单。右键该 Turn 时：

1. 复制（该条文本，已有 `writeClipboardViaBridge`）
2. 从此处 Fork（已有 `conversationApi.fork(id, turnId)`；`unnamed` / 流式中禁用）
3. 分隔线
4. 上面四项会话级动作

**Composer（可编辑）**

剪切、复制、粘贴。有选区才启用剪切/复制。不出现导出会话。

**权限卡 / 提问卡 / 工具卡**

静默或仅「复制」（有选区时）。批准/拒绝保持卡片按钮，不进右键。

### 7.4 会话列表

三处空白菜单相同。排序键统一为 **名称 / 最近活跃 / Agent**。

| 表面 | 空白命中 | 对象命中 |
|---|---|---|
| 工作区会话列表（左栏 `SESSION_LIST`） | 列表客户区，不含工具栏、不含行 | 会话行（已有菜单，保留） |
| 固定布局看板（`builtin:sessions` 列表；`builtin:columns` 分栏空白） | 列表或栏内空白 | 会话卡片（已有菜单，保留） |
| 无限画布（`builtin:canvas`） | 画布空白（非卡片、非浮动列表） | 会话卡片：目前被吃掉，应对齐看板卡片菜单 |

**空白菜单**

| 项 | 策略 | 来源 |
|---|---|---|
| 自动排序 ▸ 名称 | 接线 | 工作区：`SessionListSortKey = 'name'`；看板列表：现有 `sortField = 'name'` |
| 自动排序 ▸ 最近活跃 | 接线 | `'time'`（按 `updatedAt`） |
| 自动排序 ▸ Agent | 接线 | 工作区已有 `'agent'`；看板列表今日为 `name \| time \| status`，菜单按 Agent 排序时复用工作区同一比较函数，不新增排序协议 |
| 创建会话 | 接线 | 各面已有 `onCreateSession` / `requestCreateSessionInExecutionArea` |
| 导出项目会话包 | 薄 Host | 见 8.1 |

画布空白的「自动排序」按所选键重排卡片坐标，复用已有 `autoArrange` 的放置，而不是改成列表。排序键只决定卡片顺序，不引入新的画布文档格式。

看板现有「按状态排序」留在工具栏，不进右键（用户指定的三项是名称 / 最近活跃 / Agent）。

**会话对象菜单（三处对齐，已有为主）**

| 项 | 来源 |
|---|---|
| 归档 / 恢复 | 已有 |
| Fork 本会话 | 已有 |
| 导出为 Markdown | 已有 |
| 导出为 HTML | 已有 |
| 固定 / 取消固定 | 接线到行内 Pin（工作区列表已有按钮） |
| 重命名 | 接线到行内重命名 |
| 删除 | 接线到行内删除（危险项，底部） |

画布卡片补上同一组，不再只拦截。

### 7.5 文件树

节点菜单保持现状。用户点名的是**空白 / 根客户区**。

根行当前已打开节点菜单。空白列表（无节点像素、含根以下空隙）使用空白菜单：

| 项 | 策略 | 来源 |
|---|---|---|
| 新建文件 | 已有 | `openNewFilePrompt('')` |
| 新建文件夹 | 已有 | `openNewFolderPrompt('')` |
| 全部展开 / 全部折叠 | 接线 | 根操作条 `toggleAllFolders`；文案随 `allVisibleExpanded` 切换 |
| 复制文件树结构 | 薄 Host | 将当前已加载树格式化为缩进文本（`name/` 表示目录），写入剪贴板。不额外打全盘 API |
| 复制根路径 | 接线 | 已有 `copyAbsolutePath('')` |

节点菜单不重复「全部展开」；节点上的复制仍是相对/绝对路径与副本。

### 7.6 工作区预览编辑区

按当前激活的 Dock 面板类型分支。命中客户区；工具栏按钮本身静默。

#### 文件预览 / 编辑（Monaco 或 Markdown 预览）

| 项 | 策略 | 来源 |
|---|---|---|
| 复制文件内容 | 接线 | 已加载的 `useFileContent` 文本 + 剪贴板 |
| 跳转到底部 | 接线 | Monaco `revealLine(lineCount)` 或预览容器 `scrollTop = scrollHeight` |
| 跳转到顶部 | 接线 | `revealLine(1)` / `scrollTop = 0` |

有选区时顶部加「复制选区」。只读与可写同一菜单；不在右键里放保存（保存已有编辑器路径）。

插件接管的文件 opener（`PluginFilePreview` / `PluginArtifactEditor`）：静默，避免与插件内部手势打架。

#### 图片预览

| 项 | 策略 | 来源 |
|---|---|---|
| 复制图片 | 薄 Host | 已有预览 `src` / 二进制；能写图像剪贴板则写 PNG，否则复制文件路径并 toast |
| 将图片另存为 | 薄 Host | 保存对话框 + 已有预览字节（与 `exportConversation` 同一套 dialog/fs） |

缩放、适配保持工具条，不进菜单。

#### 浏览器页面（CEF Web Preview）

产品菜单画在地址栏/工具条层与 webview **外围**；页面文档内部的右键由 CEF 自己处理（否则无法在网页里复制）。点在浏览器面板铬（地址栏下方空白、工具条旁、webview 以外的面板垫）时：

| 项 | 策略 | 来源 |
|---|---|---|
| 返回 | 接线 | `applyIntent({ type: 'back' })`，`canGoBack` 为假时禁用 |
| 前进 | 接线 | `{ type: 'forward' }` |
| 启用元素选择器 | 接线 | 已有 `toggleElementInspection` |
| 打开开发者工具 | 接线 | `{ type: 'openDevTools' }` |

不把 Reload / Inspect Element 的浏览器壳菜单露出来：webview 外的面板必须 `preventDefault`。

#### 笔记

| 项 | 策略 | 来源 |
|---|---|---|
| 发送至输入框 | 接线 | 把笔记全文写入当前会话 Composer（`setFollowUpMessage`，追加到已有草稿末尾，中间空一行）。无打开的会话时禁用 |
| 复制笔记内容 | 接线 | 笔记 `content` + 剪贴板 |
| 跳转到底部 | 接线 | textarea `scrollTop = scrollHeight` |
| 跳转到顶部 | 接线 | `scrollTop = 0` |

笔记 textarea 内若出现选区，走可编辑菜单（剪贴/复制/粘贴），不走表面四项。右键发生在笔记面板标题或 textarea 外的垫层时走表面四项。

#### 终端

**禁区。** 拦截浏览器壳菜单，**不显示产品菜单**，避免挡住终端右键粘贴（Windows 常见）。复制继续用已有选区快捷键。

含：底部终端 Dock、编辑区终端标签、Agent 长期只读终端。只读 Agent 终端同样不弹产品菜单。

### 7.7 设置与插件

## 8. 薄 Host 能力说明

### 8.1 导出项目会话包

不新做跨会话事件包格式。`conversation_export` 今日一次只接一个 `conversationId`。

做法：取当前项目未归档会话 ID 列表（看板/工作区已在用的 `useKanbanProjectSessions`），对每个 ID 调 `conversation_export_markdown`，在用户选中的目录下写成 `{会话标题}.md`。桌面用已有 `save`/`writeTextFile`；若一次选目录更顺手，用已有文件夹对话框（打开项目文件夹那条）。失败的会话记入最后一条 toast，不回滚已写文件。

不导出归档会话，除非用户当前就在归档视图里（此时只导出归档列表）。

### 8.2 复制会话 Markdown

`exportMarkdown` 已返回字符串。写入剪贴板，成功 toast 沿用导出成功文案的「已复制」变体。大会话可能慢：复用导出的同一错误 toast，不另做进度 UI。

### 8.3 复制文件树结构

只序列化**界面已经拿到的节点**（含已展开的子树）。折叠的目录输出一行 `name/`，不在右键时全量递归磁盘。这与「复制当前看到的树」一致，也避免一次打爆 `list`。

### 8.4 终端

`useTauriTerminal` 已用快捷键复制选区。右键：

- `preventDefault` 掉浏览器壳
- 不渲染产品菜单
- 不调用 `stopPropagation` 到终端自己的 paste 处理器之前（若 xterm/Host 已把 `contextmenu` 当粘贴，让终端先处理；产品层只在事件未被终端标记处理后才 preventDefault 浏览器菜单）

实现时以「不出现 Back/Reload/Inspect，同时不挡粘贴」为验收，而不是再做一份粘贴菜单。

### 8.5 复制图片

优先 `ClipboardItem` / Tauri 剪贴板写图像。写图像失败则复制绝对路径。不引入新的图片处理 crate。

| 想法 | 原因 |

| 终端产品菜单（复制/粘贴/清屏） | 与右键粘贴冲突；清屏也不是已有一等动作 |

| 画布右键「撤销/重做/适配视图」 | 底部 dock 已有，空白菜单与列表三处对齐更重要 |

## 11. 验收

1. 在 macOS 上，工作区任意非 CEF 文档区域右键，都不再出现 Back / Reload / Inspect Element。
2. 会话执行区、文件树空白、三类会话列表空白、六类预览（文件/图片/浏览器铬/笔记/审阅/终端禁区）行为与第 7 节一致。
3. 首页、设置、插件、Git、搜索、欢迎页、合并、活动、工作流要么有上表菜单，要么静默，绝不露原生壳。
4. 终端右键能粘贴（若该平台终端本来就用右键粘贴），且无产品菜单、无 Inspect Element。
5. 每个新菜单项都能指回第 7/8 节的已有函数；没有新的导出 schema、没有新的排序存储。
6. 同一动作在工具栏与右键下的结果相同（导出路径、Fork 后的面板放置、排序结果）。

## 12. 建议落地顺序（仍不改代码，仅供后续实现）

1. 全局 `contextmenu` 拦截 + 可编辑 Cut/Copy/Paste + 禁区（终端）。这一步单独就能去掉 Inspect Element。
2. 会话执行区空白菜单（四项全是现成 API）。
3. 会话列表三处空白菜单 + 画布卡片补齐条目菜单。
4. 文件树空白三项补挂（展开/树结构/根路径）。
5. 预览分支：文件、图片、浏览器铬、笔记、审阅。
6. 其余静默面与壳层（首页空白、Git 空白、标签关闭、搜索结果）。

第 1 步是根因；其余是按面补产品菜单，互不阻塞。

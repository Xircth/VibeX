# 浏览器

在文件旁边打开网页。先共享标签，智能体才能读取或操作。在页面上运行 JavaScript 每次都会先询问。

## 使用

从右侧栏或「+」菜单打开浏览器标签。输入地址后按回车。Cookie 保存在本应用的浏览器配置里。

把标签设为「可读」或「可读可操作」后，智能体才能使用。点选元素会把页面标记插入 Composer，发送这一轮才会交给智能体。

## 配置

修改立即生效。

- **智能体工具**：列出、读取并操作已共享的标签。
- **运行页面 JavaScript**：每段代码运行前都会先给你确认。
- **默认共享级别**：应用到新打开的标签。

## 排障

页面打不开时，检查地址并确认本插件已启用。智能体没有工具时，打开「智能体工具」并新开会话。

# Browser

Open web pages next to your files. Share a tab before an agent can read or act on it. Running page JavaScript always asks first.

## Use

Open a Browser tab from the right rail or the + menu. Type an address and press Return. Cookies stay in this app's browser profile.

Share a tab as Read or Read and act before an agent can use it. Select element inserts a page token into Composer; send the turn to hand it to the agent.

## Configuration

Changes apply immediately.

- **Agent tools**: list, read, and act on shared tabs.
- **Run page JavaScript**: each snippet is shown before it runs.
- **Default share level**: applied to new tabs.

## Troubleshooting

If a page will not open, check the address and that this plugin is enabled. If agent tools are missing, turn Agent tools on and start a new session.

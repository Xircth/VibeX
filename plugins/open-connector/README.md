# Open Connector

启用后会在窗口右下角状态栏挂载连接器市场入口（`status.after-mcp`），点击即可展开连接器市场容器并管理第三方应用与 MCP 连接。本机 Open Connector 运行时提供 OAuth 授权与五件套连接器元工具。首次启用会按官方 Release 下载约 150–175 MiB 的二进制。

凭据留在本机数据目录，不写入插件配置。Agent 的五件工具只进入启用之后新建或重新绑定的会话。

## 使用

1. 在设置 → 插件里启用 Open Connector。
2. 点击窗口右下角状态栏的连接器图标（或进入设置 → 连接器 → MCP 市场）打开连接器市场。
3. 在连接器市场中选择应用并点击「连接」。
4. 新开或重新绑定会话后，Agent 即可调用已连接应用的工具。

## 配置

延迟加载工具目录默认打开，用于降低内存。允许私有网络和额外信任主机会放宽出站限制，只在你明确需要时打开。

## 数据

连接和密钥在 Host 数据目录的 `plugin-state/vibex.open-connector/`。卸载默认保留。要清空，使用插件配置里的「清除数据」。

## 排障

- 本机运行时未就绪：看插件配置里的最近错误。常见原因是首次下载失败。
- Agent 没有工具：结束当前会话或重新绑定 Agent。
- 授权完成后状态未刷新：在连接器市场点击刷新按钮。

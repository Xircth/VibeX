# 科学研究

把 K-Dense 的科研技能库整理成一套按领域开关的技能包：从选题、假设、实验设计、统计检验，到单细胞、基因组、化学信息学、医学影像、物理仿真。

**默认只启用 13 项通用科研方法技能。**其余 133 项按领域分组，装好之后不会自动注入任何 Agent——你在插件配置里打开哪个领域，才注入哪个领域的技能。

从设置 → 插件 → 插件市场的官方分类安装。默认关闭，可以卸载。

## 开启领域

设置 → 插件 → 已安装 → 科学研究 → 配置。每个领域一个开关，打开即注入。

注入链路：技能先落到 `~/.vibex/skills/.plugins/vibex.science/<技能>/`，再按 Agent 投影到 `~/.claude/skills`、`~/.codex/skills` 等目录。**新开或重新绑定的会话才会带上。**

关掉某个领域时，该领域已投影的技能会从 Agent 目录里移除；同名的、不属于本插件的技能不会被覆盖或删除。

> 技能注入到 Agent 目录后，Agent 就能读到技能文件本身。技能里附带的 Python 脚本是否执行、装什么依赖，由会话里的 Agent 按技能说明决定——本插件不预装任何 Python 环境，也不联网。

## 性能

打开一个领域，就多一批技能进入 Agent 的技能目录。技能描述会占用会话上下文，所以**只开你真正要用的领域**。这是本插件默认不全量开启的原因。

## 配置

```json
{
  "domains": {
    "general": true,
    "literature": false,
    "genomics": false
  }
}
```

`domains` 里没有列出的领域视为关闭。本包不存储密钥。

## 卸载

卸载即移除本插件投影的全部技能。`config.json` 里记录的领域开关随 Host 数据目录保留策略处理；缺省保留。

## 排障

- **启用后 Agent 没有科研技能**：确认目标领域已在配置里打开，然后新开或重新绑定会话。
- **关掉领域后技能还在**：重新投影发生在配置保存时；若仍存在，重启 Host 或切换一次 Agent 绑定。
- **技能没生效但文件在**：Agent 的技能目录是符号链接，指向 `~/.vibex/skills/.plugins/vibex.science/`。检查该目录是否可读。
- **包无法导入**：本包的 `content.skill` 使用了 `domain` 字段，需要支持该字段的 Host 版本。
